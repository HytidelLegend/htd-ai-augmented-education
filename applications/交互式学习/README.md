# 交互式学习

在本机查看学习项目、课程和知识点之间的先后关系。左侧图标栏支持项目页、图谱页和设置页；图谱页左侧为课程图，右侧为知识点图。选择项目后显示图谱入口。

## 启动

在本目录运行 `npm ci`，然后执行 `./run.ps1`。默认界面为 `http://127.0.0.1:5177`，服务为 `http://127.0.0.1:5178`；启动器使用 Python 服务，可用 `-Port`、`-ServicePort` 指定端口。前端构建产物位于 `outputs/交互式学习/build/`，启动与服务日志位于 `logs/交互式学习/runs/<run-id>/`。

本机将 `.ps1` 关联到 PowerShell 后，也可双击 `run.ps1`。再次运行会验证并关闭本应用已有启动器、服务和前端，等待端口释放后启动新实例；其他程序占用端口时会报错，不关闭其他程序。启动期间请等待依赖安装与构建，看到界面地址后再打开浏览器；使用 Ctrl+C 正常关闭应用。

启动失败时窗口保留错误提示，按 Enter 关闭；终端自动化可传入 `-NoPause`。日志路径在预检前显示，`startup.log` 保存失败详情，`service.log`、`build.log`、`gui.log` 分别保存服务、构建和前端输出。启动状态通过共享检查点记录为准备、预检、关闭旧运行、服务启动、构建、前端启动、运行、清理、完成或失败；安装、构建时中断也会清理对应子进程树。连续双击时，后一次启动等待前一次启动完成，再关闭旧实例并重启；等待超过 120 秒会提示稍后重试。

如换机后双击 `.ps1` 未运行 PowerShell，可在仓库根目录执行 `runtime/.venv/Scripts/python.exe -B -X utf8 utils/scripts/local_app_process.py --configure-ps1-open --log-root logs/交互式学习/runs`。该命令先检查现有设置，再保存配置并报告结果，只调整当前用户的 `.ps1` 双击关联，影响该用户其他 `.ps1` 文件；原命令保存为运行目录内的 `startup-entry.log`，不修改执行策略。启动应用本身不会自动改文件关联。

最小测试命令（在仓库根目录运行）：`runtime/.venv/Scripts/python.exe -B -X utf8 -m pytest applications/交互式学习/test_startup.py skills/interactive-tutor/tests/test_interactive_tutor.py::test_http_interfaces_and_pending_skip_are_idempotent -q -p no:cacheprovider`。导师完整回归使用 `skills/interactive-tutor/tests`，测试使用隔离配置，不依赖或修改本机学习设置。 已安装前端依赖时，最小测试还会运行双图回归：对 5,120 个 DAG 与目标组合枚举初始节点到目标的路径，核对边集合；验证两图渲染、支线角标、跨图关系、刷新重算和分隔条事件（拖动、边界、键盘、双击、取消及丢失捕获）。测试不写入真实项目。

## 项目与交互

读取导师项目的 `项目.json` 和 `artifacts/学习路线.json`，并显示尚未开始教学的正式导航。自定义项目位置通过导师运行状态发现；同导航去重。旧导航没有新版诊断时可查看，开始教学需要先用新版导航流程补齐。

节点已学/在学/待学分别为浅绿/浅蓝/浅红；黑色描边表示普通或选中，金色粗描边表示正在学习。点击节点时，本图以从上游到下游流动的金色边高亮所有初始节点（入度为 0）到所选节点的全部路径；再次点击或按 Enter/空格取消选择。另一张图继续联动：紫色表示前置关系，青色表示讲解关系。无关联节点不透明度 50%，屏蔽节点为 30%。右键或 Shift+F10 打开屏蔽/恢复菜单，指令在下次导师安全阶段同步；跳过不代表掌握。

两图默认均分，中间分隔条可左右拖动，左右各至少占可分配宽度的 25%；聚焦分隔条后可用左右键每次调节 2 个百分点，双击恢复均分，当前页面会话内保留比例。窄屏上下排列并隐藏分隔条。拖动保留抓取偏移，图例和缩放控件在窄面板内自动换行。调整宽度保留选择和视角；版本刷新重新计算路径，减少动态效果偏好下显示静态金色高亮。

每张图独立缩放和平移，右下角支持滑条、百分比、加减与适应按钮。默认每 5 秒检查版本并刷新，保留视角与有效选择；应用配置位于 `applications/交互式学习/config.yaml`。

设置页直接保存两个技能的合法参数到 `skills/build-curriculum-navigation/config.yaml` 和 `skills/interactive-tutor/config.yaml`，采用版本检查。技能下次安全检查点冻结并使用新配置，在对话提示变化；已发布课程与评分保留原记录。播客开关启用 `create-dialogue-podcast`；每课音频完成验证后才交付讲义，最终 MP3 位于学习项目 `播客/`，与课程 Markdown 同名；历史原件及中间产物位于 `artifacts/podcasts/`。

教学和答题在技能对话或课程 Markdown 中完成。新课程在习题末收集学习反馈，批改后处理疑问并调整下一课。网页不会执行技能或暴露题目参考答案。

详细规则与验收见本地 `docs/PRDs/交互式学习.md`（如存在）。`docs/PRDs/` 和 `docs/decisions/` 仅为本地文档，不同步到远端仓库，新克隆仓库不包含它们；公开使用说明以本应用 README 和相关 Skill 契约为准。

## 正文覆盖与新课程协议

课程规划必须覆盖每个正文要点，包括暂缓具体执行的要点（安排为支线）。学习路线以“材料覆盖”表展示要点、主支线、知识点、课程及教学块；只有 explained 块算讲解完成，前置引用、标题提及和 mentioned 不算。每个学习目标也须被讲解块覆盖。新正文要点导航初始化按同章同路线分组，进入 lesson_plan_required；Agent 检查并通过小计划补丁合并/拆分后，用 confirm-plan --revision 确认，不能机械采用一知识点一课。

五类教学块按实际需要选填，不要求每课凑齐。lesson.reference_chars_min/max 默认 800/1500，仅针对整课“课程讲解”正文的可见非空白字符合计，排除标题、Markdown 标记、链接地址及其他小节；英文按字符，公式和代码内容计入并单独统计。低于下限须补充讲解，或说明目标如何被完整覆盖；超过上限不强制截断或拆课。单知识点课程可保留，不为凑字数组合。简短材料不靠重复扩写；材料外说明显式标记。

讲解复核采用共享 Python 状态机和指纹绑定的小模板，完成前不发布、不进入播客、不接受作答；需补充的判断和理由归档，必须修改正文后重新复核。完整契约与模板字段见 `skills/interactive-tutor/SKILL.md`；已发布课程不自动重写。

新发布课程在正式习题后增加学习反馈：可选难度 A 过于简单、B 难度适中、C 过于困难（空白默认 B），以及可选疑问/其他反馈（空白表示没有）。两项不计习题数量、不计分。批改后不另问是否有疑问；空白评论直接处理难度信号，非空评论由 Agent 分类，有疑问先在 awaiting_feedback_questions 回答并留痕，再 apply-adaptation 保存下课调整。历史已发布课保持原答疑兼容流程，讲义和批改不自动重写。

下一步同时存在可学主线和支线时进入 awaiting_route_choice，展示候选并提示到 Web 图谱页查看详细路线。回复“继续/下一课”默认主线，沉默不推进；多条支线需明确选择。开启支线后先推进其后续支线，再回主线。主线结束且有未学支线时进入 awaiting_branch_continuation；暂缓后为 main_completed，支线仍待学且可恢复，不标记全项目完成。选择绑定路线快照哈希，过期后刷新。

v5/v6/v7 发布前，共享 Python 比较诊断与历史题干、选项（忽略排列）和近似度，命中后需改题或填写 reuse_review[{history_id,reason,purpose}]。完全重复仅允许明确复测；不同任务的语义辨析由 Agent 判断。报告保留复测的证据限制，不将复测答对当作新增迁移证据。脚本轮换四个正确选项位置。


Web 两图采用主线实线、支线虚线边框及指向支线的虚线入边，仅支线节点右上角显示“支”，主线不显示角标；图例标注主线与支线，缺失或非法 track 不显示为支线，提示显示“未分类”；API 节点显式返回 track。保留状态填充色、正在学习金色描边与关系外圈。主线已完成、支线暂缓的项目留在进行中。

## 课程讲解排版（v6 基础兼容）

v6 历史课程使用 `interactive-tutor-lesson-decision-v6.schema.json`。新课以文末 v7 契约为准。教学块仍关联稳定 ID、类型、学习目标、材料要点与 explained/mentioned 覆盖判断，增加结构化 `parts`；块级和知识点级 `text` 均由脚本派生。脚本预填 `parts` 的短段落模板；Agent 按语义补少量短正文，解释分段、并列用无序列表、步骤用有序列表、关键概念及结论局部加粗。长讲解使用多个 parts，不机械按字数切段、不要求每节凑齐类型。

| type | 字段 | 排版 |
|---|---|---|
| paragraph | text | 独立段落；支持局部 **加粗** |
| unordered_list | items | 无序列表；保留列表项内换行 |
| ordered_list | items | 脚本自动编号 |
| formula | latex、可选 caption | 独立 LaTeX 公式块 |
| code | code、可选 language/caption | 自动选择安全代码围栏 |
| quote | text、source、可选 url | 引用块与来源；链接限 HTTP/HTTPS |

有需要时加入公式、代码和引用。直接引文必须填写来源；材料内引用与资料外解释继续遵守证据规则，不能把无法核实的内容冒充原话。`utils/scripts/learning_teaching_layout.py` 负责结构校验、空行、缩进、编号、围栏和来源排版，`utils/scripts/learning_content.py` 统一扩充知识点正文。

排版子状态机为 `prepared → validating → rendering → verifying → completed`，失败为 `paused_error`，中断或失败恢复时重新校验结构；检查点位于导师日志的 `teaching-layout/<输入指纹>/state.json`。随后进入既有覆盖、讲解质量、题目质量和播客门禁；Markdown、可见字数统计、复核指纹、播客输入及 verify 使用同一派生正文。公式和代码内容计入原有字数统计。v6 正文保留代码标识符、公式、引文及来源链接原文，不进行全局术语替换；历史 v4/v5 保留原有呈现规则。

只改善新发布课程，历史 v4/v5 讲义、作答与批改保留读取兼容，继续/批改不会自动转换成 parts；显式重新发布使用 v7 并保留旧版本。

## 项目详情、名称与可恢复归档

项目 block 显示 `创建时间：<时间>` 和 `最后一次学习时间：<时间>`，无学习记录显示“尚未学习”，无法可靠确定创建时间显示“未知”。新项目独立保存 created_at/last_learning_at；历史创建时间可从由 utils/scripts/timestamp.py 生成的项目 ID 恢复，学习时间仅从可靠教学事件恢复，不使用文件修改时间。所有时间保持本地、不带时区的 YYYY-MM-DDTHH:MM:SS。

时间下方按钮依次为：第一行“详情｜删除”，第二行“打开项目目录”，第三行“跳转到图谱页”。点击卡片主体等价于点击详情；其他按钮不触发详情。主体与操作区采用独立按钮，支持键盘操作。

项目页右侧打开详情分屏：顶部为项目名称编辑框、保存、图谱页、删除及关闭；下方默认展开基础信息（ID、状态、时间、材料、目录）、当前课程、教学阶段、下一步事项和课程/知识点/主支线统计。知识点前置关系、课程前置关系和材料覆盖默认折叠。完成率为已学/全部节点，跳过另列；掌握度只统计已有评分证据。仅导航项目显示尚未开始教学、尚未规划课程，并保留导航中的材料要点覆盖记录。下一步展示具体操作建议，不重复教学阶段名称。窄屏上下排列。

详情由权威 JSON 派生，与学习路线.md 使用相同双图和覆盖逻辑，不解析 Markdown、不暴露题目参考答案。重命名仅修改展示名称，目录和稳定 ID 保持不变；导师和导航名称独立。导师名称同步项目 JSON 与学习文档，导航名称保存在共享展示登记、不修改共享导航内容；项目发现入口使用同一登记。

删除先明确提示可恢复，再执行归档。导师目录移入 outputs/interactive-tutor/archives/<项目ID>/，原始材料、共享导航和日志保留；归档后上游导航重新单独显示。仅导航项目归档展示登记并隐藏卡片，导航文件保留。项目页提供可恢复归档列表及恢复按钮；恢复导师目录到原位置，保留 ID、名称、课程、作答和进度，冲突拒绝覆盖。

项目管理的详细实现与恢复规则见 [导师说明](../../skills/interactive-tutor/references/usage-details.md)。浏览和设置修改不计为学习；课程发布、作答和批改等成功保存后才更新学习时间。

新增接口 GET /api/archives、POST /api/projects/<id>/manage。管理请求字段为 actionId、expectedRevision、operation，operation 为 rename/archive/restore/open-directory，rename 额外携带 title。恢复版本来自归档列表，其他版本来自项目快照；重试必须复用同一操作 ID 和请求。浏览器仅提交登记的项目 ID，Python 服务解析目录并调用系统文件管理器。

## 讲解中的引用与步骤

课程会先交代必要背景，再引用和解释材料；引用如有删改会明确标注。步骤按顺序列出，示例与步骤分开，避免混淆。讲解检查通过后才发布课程并开始答题。历史课程保持原有记录。

完整实现与历史兼容说明见 [导师 Skill](../../skills/interactive-tutor/SKILL.md)。
