# 更新历史

## 0.1.11

- 需求与验收文档改为仅在本地保留，停止 Git 跟踪。
- 明确新克隆仓库缺少本地文档时，依据公开契约执行并澄清不明确需求。

## 0.1.10

- 架构决策文档改为仅在本地保留，停止 Git 跟踪。

## 0.1.9

- 新增语音转文字、文案转逐字稿、文字转语音三个 Skill。
- 支持逐字稿确认、共享热词、语音试听、时间戳和局部修订；文字转语音支持 Edge-TTS 与火山引擎。
- 增加学习项目选择及学习材料备份、恢复机制。

## 0.1.8

- 格式转换增加通过 MinerU 将 DOC、DOCX、PDF 转为 Markdown，保留完整解析包。
- 增加共享学习项目管理、自适应诊断和学习顺序候选生成。

## 0.1.7

- 新增艾宾浩斯背诵计划 Skill。
- 词汇星图增加艾宾浩斯与葫芦背书法计划、背诵练习和日历排程，补充考试词表。
- 扩展词形、派生词及拼写关系维护，统一词库存储并支持旧数据迁移。

## 0.1.6

- 新增英语词条构建 Skill，采集多词典资料并整理释义、例句、读音和词汇关系。
- 新增词汇星图应用，提供项目词表、词典、关系图谱和收藏管理。
- 增加学习导航及交互式教学的共享图结构、证据处理和数据契约。

## 0.1.5

- 新增背书工具，支持自动提取要点、手工编辑、片段分组和分难度练习。
- 两个记忆 Skill 共用术语表，保护完整术语边界。

## 0.1.4

- 新增记忆要点标记 Skill，支持重点提取、挖空文本生成和要点编辑。
- 支持古诗文整分句背诵，并检查挖空后的主干和答案泄露。

## 0.1.3

- 文档审计扩展到应用说明、版本、状态机和数据契约。
- 敏感信息检查增加结构化审查输入校验，统一公开调用入口。

## 0.1.2

- 新增背图工具，支持图片遮罩编辑、回忆练习、项目保存和 ZIP 导入导出。
- 统一项目时间戳格式及生成方式。

## 0.1.1

- 新增关键词联想记忆 Skill，生成关键词、记忆场景和生图提示词。
- 建立共享联想记忆原则与质量检查，支持确认后生成图片。

## 0.1.0

- 建立项目骨架、插件配置、隔离环境和共享运行工具。
- 提供英语作文工具创建、写作、批改、润色及答题卡图片提示词功能。
- 提供项目任务路由、文档审计、敏感信息检查、Git 差异检查和 EPUB 格式转换。
