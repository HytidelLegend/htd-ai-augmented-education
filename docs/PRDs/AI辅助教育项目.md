# AI 辅助教育项目 PRD

## 目标

为个人学习者建立可恢复、可验证的学习资料与计划流水线。

## 首期范围

当前注册的 skills 负责格式转换、英语写作支持、学习流程辅助和英语词条批量处理；各 skill 的输入、输出和运行状态必须按自身契约分离保存。英语词条采集按《词汇星图 PRD》限定的四站和可见浏览器执行。

词汇星图作为首期之后的本机单用户 Web 应用扩展，读取 `outputs/词汇星图/` 总词库，提供单词页、收藏夹、图谱、设置和自动保存。当前只有动态的“所有单词（测试）”，正式学龄段清单待用户提供词表后建立。

## 非目标

首期不自动决定考试、不替用户生成承诺性的成绩预测，也不上传个人资料。`build-word-entry` 允许从限定四站采集证据并由 Agent 作少量结构化判断；当前不处理学龄段标签或正式引用清单。词汇星图应用不要求账号或云同步，不预置未获用户提供的考试词表。

## 验收

- 各已注册 skill 的入口命令能够生成其定义的正式产物、状态文件和事件文件。
- `verify` 能独立发现缺失、格式错误和产物缺失。
- 状态和正式产物位于规范目录，临时和日志文件不进入 Git。
- `build-word-entry` 的单词与词表状态机可暂停恢复；词条 JSON 和批次结果可独立验证，AI 内容保留生成方式、置信度及待核验状态。
- 词汇星图应用在本机能读取旧版显式迁移后的词条；单词页、收藏夹、占位词页和图谱与总词库一致，状态更新按 Schema 校验并在修订冲突或写入失败时可恢复。
