# 交互式学习 PRD

## 1. 目标与范围

- 产品名称：交互式学习；目录：`applications/交互式学习/`。
- 面向本机浏览器的课程路线与进度查看器。视觉语言、三栏布局、React + Vite 前端和 Python 本地服务参考 `applications/背书工具/`。
- 本阶段展示已有学习项目、带先修关系的有向图和进度统计。课程生成、入学测评、讲义和练习仍由 `beta-build-curriculum-navigation`、`beta-interactive-tutor` 的 Agent 流程完成；网页不提供这些操作。

## 2. 学习入口与路线选择

1. Agent 在教学前确认学习者当前水平及学习目的。学习目的用于确定优先主题、课程顺序以及后续讲义详略；已有 v2 学习档案可作为背景，但应核对是否仍准确。
2. 根据导航单元及其先修关系，Agent 一次只出一道四选一诊断题。选择位于当前已知与未知区间中点附近的单元；用户作答后更新区间，再出下一题。允许“不确定”。最多五题或边界收敛后形成粗略知识边界。答对仅代表诊断线索，不自动标记单元为已掌握。
3. 若依赖图有多个合法拓扑序，Agent 根据学习目的、诊断边界、先修约束和课程连续性选路线，并说明关键取舍。目标是让后续内容主要落在边界附近；不得违反任何先修边，且不能因单题答对直接跳过必修内容。
4. 导航阶段的排序决策把目标与测评摘要写入正式导航，并在运行日志生成可复用的 `knowledge-boundary.json`；导师可用 `assessment-import` 直接复用，避免重复提问。若没有可复用诊断，导师自己逐题测评。`beta-interactive-tutor` 在正式准备第一课前检查入口信息和测评状态；测评未完成时返回待完成状态。浏览器只读取已生成的路线与进度，不承担题目交互。
5. 导师按测评边界给证据包附上建议讲解深度：已知区间简要复习、边界附近重点练习、边界以上增加铺垫；Agent 再结合学习目的和当课证据决定最终详略。诊断结果不自动把必修单元标记为完成。

## 3. 数据与展示

- 学习项目以 `beta-build-curriculum-navigation` 的正式导航 JSON 为权威来源。默认查找 `outputs/beta-build-curriculum-navigation/runs/<run-id>/navigation.json`；对指定了自定义 `navigation_json` 的项目，从已完成运行的 `logs/beta-build-curriculum-navigation/runs/<run-id>/run-state.json` 解析项目内路径。仅列出可通过 v2 schema 校验的导航。
- 图节点来自 `navigation.units`；边来自每个单元的 `prerequisites`。按 `sequence` 和 `stage` 展示。单元卡片显示标题、阶段、模块、难度、前置单元和状态，点击后在右侧显示详情。
- 读取最近一个引用同一导航路径的 `logs/beta-interactive-tutor/runs/<run-id>/artifacts/learning-progress.json`。找不到进度时，全部节点为待学习。
- `completed` 为已学习（浅绿）；`awaiting_answer` 或 `retry` 为正在学习（浅蓝）；`pending`、`skipped` 或无进度为待学习（浅红）。`skipped` 在本阶段统计中视作未完成，不暗示已掌握。
- 右栏统计已学习、正在学习、待学习、完成率（已学习数 / 总单元数）、已有分数的平均掌握度；没有分数时显示 `—`，不显示虚假的 0%。显示课程缺口与延后项目数量。

## 4. 界面与状态

- 左栏：学习项目列表；默认打开最近的有效项目。空列表说明需要先生成导航。
- 中栏：项目标题、课程目的、颜色图例与可滚动路线图。边带箭头，方向为先修到后续；窄窗口可纵向滚动。
- 右栏：进度圆环、四项统计及所选单元详情。
- 提供加载、空状态、读取失败与手动刷新。读取失败不清空已经展示的项目；界面不写入项目或 skill 运行文件。

## 5. 服务与安全

- 服务仅监听 `127.0.0.1`，提供 `GET /health`、`GET /api/projects`、`GET /api/projects/<id>`；不提供写入、删除或执行 skill 的 HTTP 接口。
- 项目 ID 限制为正式产物目录名，拒绝路径穿越和符号链接；读取导航和进度时按 schema 校验。缺失或损坏的项目不进入列表，显式打开失败返回错误。
- 应用不复制学习资料内容，只读取导航摘要和进度；正式导航与进度各自保持原有权威路径。时间由上游 skill 的 `utils/scripts/timestamp.py` 产生，本应用不生成项目时间戳。

## 6. 验收

1. 有两个合法导航产物时，左栏显示两个项目，可切换，并展示对应标题、单元和先修边。
2. 无进度时全部节点浅红，完成率 0%，平均掌握度 `—`；匹配进度后按三色显示，统计与进度 JSON 一致。
3. 损坏 JSON、非法项目 ID、跨目录路径不能读出任意文件；服务保持可用。
4. 在 1920×1080 可同时查看三栏；较窄窗口可以滚动查看路线，不丢失节点或箭头。
5. `npm run typecheck`、`npm run build`、Python 语法检查通过；skill 的知识边界算法对逐题收敛和“不确定”有测试。
