# 交互式学习 PRD

## 1. 范围与权威数据

- 本地 React + Vite 前端与 Python 服务。教学、出题、答疑和资料检索在 Agent 对话中完成；网页负责项目、双图、屏蔽指令和参数设置。
- 所有导师调用前先运行 `beta-build-curriculum-navigation` 校验或增量维护导航；单份资料也不能绕过。有效背景和诊断不重复提问。
- 导航生成知识点依赖图；导师维护独立课程图。正式 JSON 是权威数据，Markdown 是脚本生成的视图；对话只展示 Markdown。参考答案保存于课程 JSON，出题 Markdown 不展示答案。
- 学习项目根目录只放 `项目.json` 和中文 Markdown；其他 JSON 位于 `artifacts/`，课程 JSON 位于 `artifacts/lessons/`，`课程/` 只放 `课程_X-Y.md`。
- 运行快照、状态、事件、中间模板和未确认笔记位于 `logs/<skill>/runs/<run-id>/`。时间统一通过 `utils/scripts/timestamp.py` 产生。

- 学习项目新增 `学习材料/<source-id>/<材料版本哈希>/<原项目相对路径>`，逐字节备份 Markdown 和引用的本地图片、附件及关联 Markdown，保留相对目录，不修改源文件，不下载远程资源。权威备份清单位于 `artifacts/学习材料备份.json`，历史版本保留。
- 备份采用共享 Python 状态机：规划、等待整批路径批准、复制、校验、完成；失败可恢复，目标冲突暂停。教学前校验及证据读取使用项目内副本；副本损坏禁止回退原文件。已有项目下次继续时补建备份。
- 原资料变化通过导航增量流程及 `supply-navigation` 显式引入，新增版本不覆盖旧副本。教学启动待备份确认时状态为 `backup_required`，确认计划哈希并完成备份后才能进入 `ready`。

## 2. 学习导航与诊断

备份状态须校验合法迁移；路径批准涵盖材料、正式清单及新增历史清单。资源识别忽略代码示例与未使用引用；正式发布将材料清单、项目 JSON、Markdown 视图纳入同一可回滚事务。初始化失败保留待备份检查点。写入路径与输入材料重合时拒绝执行，产物不得写入 `runtime/` 或日志目录。

1. 背景不足时在对话中讨论当前水平、目标及必要约束，不生成用于询问背景的课程。已有档案核对后复用。
2. 根据目标知识点及其前置范围进行目标优先自适应探测，优先共享基础和缺少证据的重要主题；逐题调整探测对象，不在任意拓扑序上全局二分。
3. 诊断默认最多 5 题，参数位于导航 skill 的 `config.yaml`。每题四个实质选项，第五项固定为“没听过 / 不清楚 / 没把握”；不得用“是否听过名词”作为题干。
4. 正确、错误、不确定分别记录；单题答对不代表掌握，未测区域保持未知，后续正式习题继续补充证据。达到上限形成初步判断，不保证评估全图。
5. 生成最多 10 条去重合法候选拓扑序列，数量可配置。保留全部实际生成候选、分项分数、停止原因和历史版本，按总分非升序排列，推荐最高分的一个或多个并说明理由。
6. 默认评分权重为目标匹配 40%、背景匹配 30%、难度平缓 15%、主题连续 10%、后续解锁 5%。学习路线调整时参考仍合法候选；依赖图改变后重新验证和评分。

## 3. 双图、课程规划与状态机

- 一个课程可讲多个知识点，一个知识点可在多个课程中讲解、复习和应用；每个未显式跳过知识点至少被有效课程讲解覆盖，前置引用不算覆盖。
- 每课默认最多 3 个知识点，正式选择题最多 3 道、问答题最多 2 道；引导问题和补充追问不计入。每个本课要学习的知识点至少有一道正式习题，多知识点问答题需要可分别判定的评分点。超过容量应拆课。
- 课程依赖必须与知识点依赖一致；同课内按知识点顺序讲解，跨课依赖明确知识提供课程，不将所有复习课程机械连为前置。双图必须无环。
- 按整体板块划分章节，再分小节。稳定课程 ID 与编号分离，显示编号为 `X.Y`、文件名为 `课程_X-Y.md`；新增课程追加所属章节的小节编号，实际学习顺序由图决定。
- 区分主线和支线。主线必学；支线可暂缓、显式跳过、恢复。主线依赖的支线基础必须升级或提供替代课程。
- 教学状态为 `ready → lesson_decision_required → awaiting_answer → review_decision_required → awaiting_questions → ready/completed`。失败保留检查点；重复提交和非法迁移不能越过门禁。
- 用户交完习题后先批改、反馈优点与不足、更新项目文档，再询问是否有疑问。提出疑问时回答并继续答疑，**用户明确没有疑问后才允许准备下一课**；沉默、超时、批改完成都不能替代确认。
- 新问题可查资料后增加支线课程，先维护导航，再修改课程计划并同步双图。已发布课程保留历史；删除/退出课程必须检查覆盖和依赖。
- 用户可明确跳过知识点或课程并指定后续课程；保持依赖边，在后续课程开头标注基础已学/待学、对应小节及跳过情况。跳过课程不自动跳过其中知识点。
- 所有未显式跳过知识点完成覆盖学习，且未跳过课程完成后，项目进入完成状态；暂缓支线仍属待学。跳过不计为掌握。

## 4. 学习文档

| 文档 | 内容 | 更新时机 |
|---|---|---|
| 学习路线 | 知识点清单与依赖、课程清单与依赖、Mermaid 双思维导图、主支线、状态；引导打开图谱页 | 每课结束、导航同步、计划及状态调整 |
| 总结 | 每课概述、核心要点、重要公式 | 每课结束累计更新 |
| 学习报告 | 已学内容、掌握优点与不足、逐知识点分类和习题依据 | 每课结束累计更新 |
| 笔记本 | 内容定位、背景和整理稿 | 用户确认当前草稿后 |
| 错题本 | 薄弱点、普遍规律、纠正方法、原习题例子及用户回答 | 错误或不完整批改后自动更新 |

- 面向学习者使用“知识点”“课程”，不使用 unit/lesson 术语。
- 学习路线内的知识点、课程双思维导图采用 Mermaid `flowchart LR`，箭头表示前置到后续，不调用生图工具。知识点标签为名称及学习状态，课程标签为编号、标题、主支线及学习状态；完整保留多前置、孤立和已跳过节点，历史退出课程不展示。
- Python 从权威双图生成思维导图，使用共享 Schema 与模板；依赖图或节点信息更新时，在同一事务中发布 JSON、依赖表与思维导图。文档子状态机为校验双图、渲染、验证、发布、完成，失败保留日志检查点并允许恢复；验证必须发现缺失、过期或不一致图示。旧项目通过导师 `resume` 补齐图示。
- 文档恢复校验并保留未完成检查点的迁移历史，再从权威数据重新校验双图；损坏检查点拒绝覆盖。教学状态检查点、计划模板与项目文档同事务发布，失败回滚且不推进内存模型版本。
- 作答区域逐题采用粗体标题、引用块、清晰占位提示和分隔线。用户只编辑作答区域；正文变化应拒绝批改，检查后答案变化需重新检查。
- 选择题脚本判分，问答按逐知识点评分点判断。学习完成状态与掌握程度分离：良好 ≥80%、中等 ≥60%、其余一般；缺少评分证据显示“未评估”。
- 播客开关默认 false，目前仅占位。开启时显示待实现，不伪造音频产物。

## 5. 页面与图谱交互

- 左侧参考词汇星图：一列图标，悬停或键盘聚焦展开，顺序为项目页、图谱页；设置页固定在底部。
- 项目页：上方进行中项目，水平分隔线，下方已完成项目。选择项目后才显示图谱入口。只有导航、没有课程规划时仍可查看知识点图。
- 图谱页左右分屏：左为课程依赖图，右为知识点依赖图；窄屏上下排列，保持两图独立操作。
- 节点填充：已学浅绿、正在学习浅蓝、待学浅红。普通黑细描边、选中黑粗描边；正在学习金色粗描边。
- 点击课程，右图用紫色外圈表示前置知识点，青色外圈表示本课知识点，无关联节点不透明度 50%。点击知识点，左图紫色外圈表示以它为前置的课程，青色外圈表示讲解它的课程。
- 关系高亮用额外外圈，不覆盖金色学习描边；同时存在两种关系显示双圈。两图左下角显示关系、状态和屏蔽图例。
- 两图分别统计已学、在学、待学、跳过及完成率；知识点图显示有评分证据的平均掌握度，没有证据显示“—”。完成率为已学数/全部节点数，跳过另列。
- 右键或键盘菜单支持屏蔽/恢复。屏蔽节点不透明度 30%，优先于无关联的 50%，不叠乘。操作后显示“待同步”；下次导师安全检查点消费指令并维护双图。恢复后可补学。
- 两图右下角独立提供缩放滑条、百分比、放大/缩小按钮和适应画布按钮，默认范围 25%～400%，可拖动画布。
- 默认每 5 秒检查图和状态版本，变化时读取一致快照并刷新。保留选择、缩放和平移，失效选择清除；同步失败保留上次有效数据。窗口重新获得焦点立即检查，轮询间隔存于应用配置。

## 6. 参数设置与服务

- 设置页分组编辑两个 skill 参数，并保存到对应 `config.yaml`。数量、权重总和、阈值顺序及布尔值由共享 Python 校验。
- 每次运行冻结配置；同项目再次调用时检查有效参数，变化则更新快照、保留历史并在对话提示。配置在下一个安全检查点作用于本次运行，不改已发布课程和已提交评分。
- 保存使用版本检查与原子写入；冲突提示重新加载，不默默覆盖外部修改。播客开关标注待实现。
- 服务只监听 `127.0.0.1`，不执行 skill，不直接从网页修改教学正文/进度/依赖图。写接口仅保存屏蔽/恢复指令与合法配置。
- 接口：`GET /health`、`GET /api/projects`、`GET /api/projects/<id>`、`GET /api/projects/<id>/version`、`POST /api/projects/<id>/actions`、`GET /api/config`、`PUT /api/config/<skill>`、`GET /api/ui-config`，写接口支持 CORS 预检。
- 校验 ID、来源、路径、链接、请求大小和字段；不向网页暴露课程参考答案。项目锁与提交版本保证快照一致，操作 ID 支持幂等。

## 7. 验收

1. 单份资料也必须先导航；导师不能重复入学诊断或越过答疑状态。
2. 诊断第五选项不记为正确，未测区域保持未知；生成候选数量受配置限制，全部保留且分数非升序。
3. 多对多覆盖、课内顺序、跨课依赖、删除课程、显式跳学与恢复均校验；课程编号不因路线顺序改变而重写。
4. 正式习题上限、逐知识点检验、参考答案隐藏和作答区编辑检查有效。
5. 每课批改后五类文档同步更新；笔记未确认不写入，错题保存规律与例题。
6. 项目页分组、双图联动、描边优先级、50%/30% 透明度、图例和缩放正确；版本变化自动同步且保持视角。
7. 设置保存、版本冲突、配置冻结/历史、当前运行安全点生效和播客占位正确。
8. 最小 CLI/HTTP 接口测试、已有相关回归、Python 检查、TypeScript 检查和前端构建通过。
9. 源文件字节不变；本地资源及相对引用完整；源材料变化或移走后继续教学仍读取副本；显式导航更新保留旧版；副本损坏、路径越界、同名冲突、未批准计划和失败恢复均正确处理。

## 8. 逐项复核补充约束

- 自适应诊断依据上一题的观察调整后续或前置探测；更换目标知识点集合时不能复用原诊断。未测区域仍保持未知。
- 导航同步以及重新评分均保留此前实际生成的候选路线；历史候选不受当前生成数量上限裁剪。
- 数量上限降低后，未发布课程模板使用选择题与独立评分的综合问答题覆盖知识点；发布时重新检查当前上限。准备中的课程可退回规划拆分。
- 选择题依据项目内已存参考答案与作答直接判分。每个回答不完整的知识点都需错题归纳，选择题例子保留选项；文件作答切换到聊天作答后不再依赖旧文件检查哈希。
- 笔记草稿及来源哈希必须与用户确认版本一致；确认状态单独记录，未经确认的变化禁止写入。
- 允许用户屏蔽正在学习但尚未批改的课程并选择后续课程，保留待学基础；已经提交的答案仍先批改并进入答疑门禁。课内提问保留当前教学状态。
- 恢复并重新发布课程须保存此前讲义、作答与批改版本；不能覆盖历史而没有记录。
- 配置变更提示在成功返回后确认送达，失败重试不能丢掉通知。屏蔽和由知识点屏蔽派生的跳过课程均计入跳过统计并使用 30% 不透明度。
