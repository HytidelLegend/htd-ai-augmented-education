# 词汇星图 PRD

## 1. 目标与范围

- 产品名称：词汇星图；应用目录为 `applications/词汇星图/`，运行数据为 `outputs/词汇星图/`。
- 面向中国不同英语学龄段与考试词表，制作可追溯、可分级展示的英语单词精学资料。当前版本仅有“所有单词（测试）”选项，正式词汇表由用户以后提供。
- 同一单词在总词库只保存一份完整词条；各学龄段只保存对该词条的引用和展示选择，不复制释义、例句或搭配。
- 提供项目页、词汇星图页、词典页、背单词页、可上下滚动且关联计划的日历页、收藏夹页、单词页、设置页和自动本地持久化。当前为本机单用户 Web 应用，不要求账号或云同步。
- 本 PRD 规定 `build-word-entry` 的公开流程与词汇星图应用契约；本阶段实施词条与词表批次 skill，以及本机单用户 Web 应用。正式学龄段词表仍待用户提供。
- 这是总项目 PRD 所述首期范围之后的扩展需求；总项目 PRD 同步记录本阶段应用边界与验收。

### 1.1 项目与测试词表

左侧页面切换栏从上到下为项目页、词汇星图、词典页、背单词页、日历页、收藏夹。收起时只显示图标，鼠标悬停或键盘聚焦时展开图标与名称。每个项目对应一个词表；首次默认项目从 `tmp/dicts/test_20_words.jsonl` 导入 20 个选定单词，保留来源字段；混合词性的 `tip`、`extraterrestrial`、`disgrace` 拆分为独立义项。后续项目可由 TXT、JSON 或 JSONL 词表建立。项目名与词表在项目设置对话框编辑；图谱标题与节点统计之间另有当前项目名编辑框，Enter 或失焦保存、Esc 撤销，修订冲突或写入失败保留草稿并允许重试。词典页搜索所有项目词表与已建词条，按完整匹配、前缀匹配、其他包含匹配排序，同一匹配层级中当前项目的词优先；未加入项目的已建词条标注“未加入项目”。点击已建词条进入单词页，待建词进入建词条入口。背单词页关联项目词表；日历页展示计划覆盖日期及当日内容。

“词汇星图”品牌文字随左侧栏一起展开或收起；界面顶部不另设“单词不是一个一个背的”、收藏夹或设置入口。收藏夹保留在左侧页面切换栏，设置入口位于左侧栏底部。

项目页标题行右侧提供“新建项目”按钮，打开禁用背景的模态导入对话框，不再常驻新建表单或当前项目的整块单词表。各项目卡片分别提供预览、打开图谱和设置；预览在右侧分屏展示该项目词表；项目名、单词列表标题、关闭按钮及去重后的实际词数固定在顶部，只有下方单词列表滚动。设置对话框可编辑项目名与每行一个英文词的词表，单词数由去重后的词表计算且只读；保存时规范化、去重并保持首次出现的顺序。词表去重后若仅顺序变化，现有计划不重新排程；若单词集合变化且存在关联计划，先询问是否重新生成排程：同意则调用现有排程状态机并清空相关计划的通过记录，不同意则保留原排程。项目删除须二次确认，且须先处理关联背诵计划；至少保留一个项目。删除项目不删除总词库中的单词笔记文件。

总词条与收藏夹跨项目共用；熟悉度按项目分别保存，以当前项目控制图谱颜色。旧全局熟悉度只迁入首次默认项目，其他项目初始均为“陌生”。项目词表保存规范化 `wordId` 与词面，不复制释义。当前学龄段选择仍独立于项目，只有“所有单词（测试）”是正式可用选项。

20 词测试项目原有 19 条派生词和 9 条适用词形变化的 `field_not_confirmed` 缺口已经过独立、可恢复的 Agent 审核。审核包逐字段列出本次来源候选和证据摘要；Agent 只选择有直接证据支持的候选并写简短原因，脚本校验并发布。首次审核发布了 2 条有直接派生证据的关系；随后从既有来源例句中补核了 9 个词的 22 条规则词形。另由确定性状态机依据已核实的词性及保守拼写规则，补入 10 个词条的 19 条规则推导词形，逐项标注“规则推导 · 待核验”，并记录规则版本及词性证据；这些形式不能冒充来源直接证实。新建词条在建词状态机发布阶段执行同一规则，历史词条可用独立状态机补齐。`outputs/词汇星图/family-reviews/<wordId>.json` 保存直接来源审核结果：`verificationStatus: automatic_passed` 表示审核判断已由脚本验证并应用，`outcome` 区分 `published` 与 `no_supported_candidate`。历史 `gaps.json` 保留原采集时的缺口事实；界面对确无形式的字段显示“已复核现有证据 · 暂无可发布内容”，有待核验规则形式时明确显示其状态。新证据到来时重新审核并可将对应形式升级为来源支持；不可数、仅复数名词及不能可靠套用的规则不强行补齐。

## 2. 信息来源与采集边界

本期只选用用户提供的网站中的以下四站，适配器固定使用这些官方入口，不把第三方转载页当作来源：

- [Cambridge Dictionary](https://dictionary.cambridge.org/)；英汉简体词典入口为 [English–Chinese (Simplified)](https://dictionary.cambridge.org/dictionary/english-chinese-simplified/)：负责英汉简体释义、学习者英英释义、英美读音、语法标签与例句的主要核对。
- [Oxford Learner’s Dictionaries](https://www.oxfordlearnersdictionaries.com/)：负责学习者释义、语域和语法标签、英美读音、词形、短语与学习优先级的交叉核对。
- [Longman Dictionary of Contemporary English（LDOCE）](https://www.ldoceonline.com/)：负责易懂英文释义、搭配、短语、例句和常见用法的交叉核对。
- [Thesaurus.com](https://www.thesaurus.com/)：按义项提取同义、近义与反义候选。候选须回到前三站核验具体义项、语域与搭配后才能成为正式关系；网站的强弱分组不直接决定本产品的同义／近义类型。

OED、Collins、Merriam-Webster、Vocabulary.com、Dictionary.com 和 WantWords 本期不进入自动采集链。Thesaurus.com 仅用于发现关系候选，不作为关系的权威判定来源。缺失字段可以留空并标记待补，不得虚构，也不因不同网站词义编号不同而按序号机械合并。网站可用性以实际运行结果为准；某站失败时保留已取得的证据，标记覆盖不足，允许重试，不把失败当成“该词没有此义”。

来源取舍规则：中文释义优先核对 Cambridge 英汉简体词条；英英释义、读音、语法、语域和搭配以三家学习词典能定位到的具体义项为证据，不以某站词条顺序作权威顺序。同义、近义、反义候选由 Thesaurus.com 按义项分组和输入词表内的关系发现产生，再回到学习词典核验。证据矛盾时保留各站说法和定位，进入质量复核；不得用简单多数投票或 AI 猜测覆盖冲突。每站只采集它实际提供的字段，缺少音频或个别标签不视为解析成功。

采集通过 Python 浏览器自动化驱动可见浏览器。遇到登录、验证码或站点要求的人机操作，状态机暂停，在当前可见窗口提示用户完成，再从检查点继续；不得自动绕过验证码或把账号、密码、Cookie 写入正式产物。访问限速、失败重试和站点要求由适配器统一处理。本期按用户的本地学习用途设计，不开展商业授权方案；实现时仍须遵守仓库的来源、许可证和行为规则。

## 3. 总词条与学龄段数据

### 3.1 总词条

每个规范化单词只有一条完整的正式词条记录，唯一存储于 `outputs/词汇星图/dicts/a.jsonl` 至 `z.jsonl` 的对应分桶中，并有稳定 `wordId`。所有项目只保存引用；建词、审核和恢复流程通过共享记录接口直接读写该词库，不再维护长期 `entries/<wordId>.json` 副本。运行归档只用于审计和验证，不作为可编辑词库。同拼写的不同词性、读音、词义和同形异义情况都保存在这个词条中；图谱对它只画一个圆形节点。总词条至少支持：

- 单词原形、别名或拼写变体；按英音／美音及词性或用法关联的多组 IPA 与音频来源。不得把名词、动词的不同读音压成一组。
- 按稳定 `senseId` 区分的义项，包含词性、中文和易懂英文释义、名词可数性、动词及物性、语域、英美差异、来源及候选顺序。语域至少覆盖 formal、informal、spoken、written、approving、disapproving，允许按来源增加 slang、technical 等标签；区分“词条适用”与“仅某义项适用”。核心释义由学龄段引用选出并单独放在页面前部，其他释义后置；同一词在不同阶段可以有不同核心义项。
- 屈折变化与派生词分开记录。屈折变化包括可数名词复数、动词过去式／过去分词／现在分词／第三人称单数，以及适用时的比较级／最高级；不规则形式必须显式记录。每个词形指回所属总词条；派生词已有独立词条时以 `wordId` 双向关联，尚未入库时只记候选拼写和待采集状态，不复制另一词条内容。
- 每个保留的义项至少一条例句；常用短语、搭配、俚语、习语按适用义项关联，不将词条级候选误当成所有义项通用。
- 同义词／近义词、反义词、拼写相似分为不同关系，关系指向目标 `wordId`。语义关系必须关联能核验的源义项与目标义项；义项不能确定的候选不发布为确定关系。拼写相似是词条级关系，不绑定义项，也不推出语义相关；界面称为“拼写相似（可能易混）”。
- 每个可发布内容项的来源记录，以及生成方式、验证状态、创建和更新时间、版本号。

英文释义优先使用该学龄段已学或较基础的词；用定义词依赖检查避免直接和间接循环定义。中文和英文释义必须指向同一义项。例句应自然、无歧义，体现目标义项及其语法形式。对一个已入库单词再次生成时，按稳定 ID 更新原词条并保留已核验内容及阶段引用；新来源不得无提示覆盖用户修订或令引用失效。

拼写相似使用两个规范化词面的字符**子列**，不是连续子串。令 `LCS(a,b)` 为两词最长公共子列的字符数，字符相对顺序相同即可，中间允许跳过；相似度为 `2 × LCS(a,b) / (len(a) + len(b))`，达到或超过 `0.75` 即判为拼写相似。词面沿用项目的 NFKC、首尾去空白、连续空白合并及大小写折叠规则；规范化后保留的词内空格、撇号与连字符也参与长度及子列计算。归一化后相同的词不形成自关系；已明确为同词别名／拼写变体或屈折词形的词对沿用原有关系，不另建拼写相似关系；已确认同族的词对优先归入词族，不参与拼写计算，也不保存或显示拼写相似边。后续词族确认时清理已有拼写关系，包括历史已审核的拼写关系；已独立建词条的屈折词形仍归入原词词族，词形之间不另建拼写相似关系。此分数只断言字面相似，不能当作学习者必然易混的证据；关系依据可由两个词面及确定性公式重算，无外部页面证据时 `sourceRefs` 为空。

1.3 词条中每个例句、搭配和短语内容项必须有独立中文翻译及来源或 AI 生成标记；例句额外保存英文目标词与中文对应词的左闭右开字符区间，Markdown 由脚本加粗，JSON 正文保持纯文本。来源提供成对中译时记录该例句的具体定位；没有来源中译时可由 AI 补充并保存两位小数置信度与待核验状态。搭配和短语的译文不加粗。已有词条升级时保持稳定内容 ID，缺译进入可恢复的质量复核，不静默丢弃。

拼写关系维护入口为 `skills/build-word-entry/scripts/spelling_relations.py`，支持 `start --full`、增量 `start`、`status`、`resume` 和 `verify`。首次汇总所有已有项目及总词库中的规范化词面；新增或编辑项目后，仅计算新增词与旧词、以及新增词之间的词对。`spelling-index.json` 使用 `utils/references/dictionary-spelling-v1.schema.json`，保存全局词面、算法版本、阈值、无序词对的 LCS 长度和发布状态；不复制词条正文。两端词条齐备后双向写入 `relationships[]`，未齐备时由索引展示已确认的拼写相似关系及待建节点。待建表示词条未建立，不表示字面相似待核验。总览显示当前可见节点间的词对，包含已显示的词形与派生节点，聚焦可展开项目外直接相似词，遵循原有筛选和 500 节点上限。总览展示当前可见节点间全部符合筛选条件的拼写相似边，不设置每节点连接数限制；继续排除同族、去重并遵守 500 节点上限，选中节点的展示策略不变。

维护状态机为 `prepared → snapshotting_vocabulary → selecting_pairs → calculating_similarity → preparing_updates → validating_updates → committing → verifying → completed`，错误进入 `paused_retryable_error`，恢复继续原检查点；日志位于 `logs/dictionary-spelling/runs/<run-id>/`。多分桶发布保存可恢复事务日志，修订冲突暂停；重复运行不得重复关系或无故提高词条修订。 `verify` 核对正式索引与运行发布结果、LCS 重算、别名／词形／词族排除、两端词条就绪状态及双向记录。历史词面即使已移出项目且无关联边，仍可作为单节点聚焦。

旧词条迁移采用 `prepared → collecting → validating → committing → verifying → cleaning → completed` 状态机，日志位于 `logs/dictionary-migration/runs/<run-id>/`。较新修订合并到唯一 JSONL 词库；同修订内容冲突则暂停。校验通过并复核原文件指纹后才清理旧 `entries/` 文件，归档快照位于日志；已有和未来项目均不得复制词条。

### 3.2 学龄段引用

规划每个学龄段／考试一份引用清单 JSON，以稳定 ID 引用总词条中的 `wordId`、所选 `senseId` 及其所选例句、搭配、短语和关联词 ID；明确列出哪些义项属于本阶段的核心释义、哪些属于更多释义，并分别保存展示顺序。单词页关联词与图谱语义关系须同时满足阶段关联词选择及源义项属于本阶段所选 `senseId`；一个阶段只覆盖部分义项时，不展示其他义项对应的关联词。历史语义关系若缺少可靠的源义项 ID，则在正式阶段隐藏并进入质量复核，不推测归属。拼写相似是词条级关系，不受源义项筛选，但仍按阶段关联词选择和阶段外节点显示开关处理，并标明“词条级关系”。顺序由该阶段词表、教材或考试用途优先，其次参考来源中的常见性；没有可靠频率证据时标注“学习顺序”，不声称为客观词频排名。一个词可属于多个清单，清单不复制内容正文。引用目标删除或变更时，校验器阻止悬空引用或执行明确迁移，不静默丢失选择。

当前只提供“所有单词（测试）”：它动态包含全部已入库词条及其已发布义项和关系，便于验证应用；不预置或臆造小学、初中、高中、四级、六级、专八、考研、雅思、托福等词汇表。用户以后提供词表时再建立相应引用清单。用户在图谱将灰色关联词“加入”当前学龄段时，创建该词的阶段引用并默认选取总词条已核实的核心义项；若缺少合格核心义项，显示待完善状态，不编造释义。“所有单词（测试）”已包含全部词，该按钮在此选项下不显示。测试词表若无已通过的核心义项，暂取首个未驳回义项作为核心展示，并明确标注“待核验”；展示不改变核验状态。

### 3.3 来源与 AI 状态

释义、读音、词形、例句、搭配和关系等内容项各自有独立溯源，不能仅给整个词条标一次来源。来源记录包含站点、页面 URL、页面义项定位、获取时间和证据摘要。内容生成方式区分 `source_supported`（来源支持）、`ai_generated`（AI 生成）及仅用于词形的 `rule_derived`（规则推导待核验）；规则词形的词性依据与直接词形证据分开保存。AI 生成的内容仍可附来源以供验证，但不能因此改写为来源原文。

`ai_generated` 必须有 `confidence`：范围为 0.00–1.00，表示“内容正确且适合目标义项”的综合把握。正式 JSON 中它是数值，序列化时固定写成小数点后两位，例如 `0.85`、`1.00`；不可用字符串、整数或更多小数位。JSON Schema 校验数值范围和 0.01 步长，发布脚本另校验原始 JSON 文本确实保留两位小数，避免普通 JSON 解析再序列化把 `1.00` 写成 `1`。置信度是待校验的质量信号，不能代替来源或自动视为事实。`source_supported` 不填写该字段。各项另有 `verificationStatus`，至少区分待核验、自动通过、人工通过和被拒绝；低置信度在展示中提示复核，不单独阻止入库。证据冲突或义项对应不明进入质量复核。

## 4. 词汇表批量处理与单词 JSON 生成（build-word-entry）

### 4.1 常用入口：词汇表批量输入

常用操作为一次提交一份用户词汇表。支持 UTF-8 文本文件与内联文本（一行一词）、指定单词列的 CSV，以及含 word 的 JSON 对象数组或 JSONL 逐行对象；core_meanings 可作为词性与释义提示；当前不处理学龄段标签，也不能假定词表已进入应用设置。脚本先保留原始输入及其哈希，再规范化拼写、去重并记录原始顺序；每个词调用下述独立单词流程，支持断点续跑，单词失败不清空已完成词条。重复批次发现现有 `wordId` 时更新原总词条而非复制一份。

逐词生成后必须对整份输入词汇表再做一次关系发现。脚本建立词形与词族索引，检查表内词对是否可能有同族／派生、同义／近义或反义关系；还应查找已采集的短语、搭配中是否出现同批其他词。同义／近义／反义候选同时结合 Thesaurus.com 的义项分组结果。拼写相似由脚本对规范化词面计算精确最长公共子列相似度，达到 `0.75` 且不属于已知别名、屈折词形或已确认同族词时自动确认，无须 Agent 对字面相似作判断；用长度差和字符出现次数等不会漏掉达标词对的上界剪枝，不能把共同前缀、共同连续子串或 `SequenceMatcher` 分数当作必经筛选或最终判据。不能只依赖网站返回的邻居，也不能只做低效的全表逐对模型提问。两端均已入库且经对应规则核验的关系写入总词条的稳定关系 ID；两词均在本批词表内时记录为“表内关系”，便于图谱优先展示，但不复制一份团间边数据。搭配关联保留在义项／搭配数据中，不强行变成图谱的第四类团间边。表外语义候选经 Agent 确认后保留词面正式关系；无法确认时保留待采集引用，并在图谱中以灰色半透明占位节点、虚线及“待核验”状态展示；点击可打开占位词页。

关系发现不递归触发表外词的词条构建。表外关联词先保留拼写、来源词及义项、关系类型、证据和待采集状态；候选引用须持久关联到来源词条，供重启后的关联词列表与占位页读取，不能只留在一次批次的运行报告中。仅在用户明确点击“新建词条”或该词进入后续输入词表时，才启动该词的构建流程。待采集候选不得冒充已核验的正式关系，也不因候选数量增加而批量创建总词条或图谱节点。

批次状态机在单词状态机之外单独维护：`prepared → validating_list → normalizing_list → processing_words → discovering_intra_list_relations → verifying_relations → publishing_list_result → completed`；单词级暂停、失败、重试及用户浏览器操作不会让整个批次丢失进度。批次结果记录输入词表来源、已完成／待补词、表内关系、来源覆盖率和对应单词运行 ID。学龄段标签和阶段引用清单留待后续版本。

### 4.2 可复用的独立流程：单词 → JSON

输入必填一个单词；可选词性与释义提示。提示用于消歧，不限制总词条对该单词其他已证实信息的采集。本版暂不接受学龄段输入。输出为通过校验的单词 JSON 和可导入总词库的状态；未完成或证据不足时返回结构化缺口与可恢复状态，不伪称完整。

当前词条构建 skill 为 `build-word-entry`。

已确认的表外同义、近义和反义关系允许先以词面写入来源词条的正式关系字段，不自动创建目标词条或图谱节点。目标词条建成后仍需核对目标义项，才能补齐双向链接；Agent 排除的来源候选不展示，无法判断的候选继续待核验。直接派生词的证据在单词流程采集和审查，不再固定记为“未采集”。

### 4.3 单词状态机

使用可恢复的显式状态机：`prepared → validating_input → opening_browser → collecting_sources → parsing_evidence → aligning_senses → building_candidates → awaiting_small_ai_decision → validating_entry → verifying_sources → verifying_relation_candidates → publishing → reviewing_existing_links → completed`。登录或验证码时从相应采集状态进入 `paused_user_browser_action`，用户完成后恢复；词义冲突、缺少义项例句或无法确认的关系进入 `paused_quality_review`；网络或解析错误进入可重试失败状态。所有状态转换、重试次数和恢复位置由脚本记录，不靠 Agent 自行推测。

Python 脚本负责浏览器控制、站点适配器、证据提取、候选匹配、稳定 ID、模板填充、JSON schema 校验、引用检查、去重、置信度格式化与原子发布。Agent 仅在多来源义项对齐、中文对应关系、例句适切性等脚本无法可靠判定处，基于脚本准备的证据包填写少量结构化判断。脚本须复用到任意输入单词，不为单个词写特化兜底逻辑。通用浏览器检查点、状态机、结构化读写、来源规范化及校验逻辑优先放入 `utils/`；站点专用解析放在 skill 适配器中。

正式单词产物位于 `outputs/<选定 skill 名称>/runs/<run-id>/`；文本日志、状态机检查点和中间证据包位于 `logs/<选定 skill 名称>/runs/<run-id>/`，不纳入 Git。通过结构、来源定位和引用校验的结果导入 `outputs/词汇星图/` 总词库；AI 生成释义和例句可带 `pending` 状态直接入库。时间戳统一通过 `utils/scripts/timestamp.py` 产生，运行产物不得写入 `runtime/`。不保存原始网页快照；浏览器会话的敏感状态不得进入正式词条或提交内容。

1.3 单词状态机在发布前增加 `verifying_content`：脚本逐项核对读音与词形在本次页面的候选、来源定位、词性、口音及适用的拼写规则，满足条件后标记 `automatic_passed`；未满足则保持 `pending`，并在 `gaps.json` 的 `verificationGaps` 按内容 ID 报告原因。该状态只表示确定性核对，不表示人工听音。旧词条待补译文清单逐内容 ID 生成，避免相同文本跨义项时漏列。Agent 判断须绑定本次证据摘要；关系候选 ID 相同不能替代对新证据的复核。1.0–1.2 历史产物仍按其原版本契约验证。

1.4 词条在来源和结构检查后进入独立、可恢复的内容审查阶段。脚本按义项准备中英文释义、例句、搭配、短语及各自译文的内容 ID、文本和来源；Agent 判断义项对应、译文准确性与用法适切性，可暂缓个别内容项。已审查通过者标记 `agent_passed`，保存本次运行、决定和证据摘要引用；暂缓者维持 `pending` 并列入内容缺口。缺来源的 AI 生成内容也可在 Agent 核对后通过，但必须保留 `ai_generated` 与原置信度。`automatic_passed` 专用于脚本可确定性核对的项目；结构检查、来源存在或零字段缺口都不能替代内容审查。旧版运行不改变状态序列。

### 4.4 生成质量门槛

- 每个发布义项至少有一条例句，例句须体现该义项；缺失时可由 AI 生成，但保留 `ai_generated`、两位小数置信度和验证状态。
- AI 生成释义和例句通过结构检查后直接入总词库，保留 `verificationStatus: pending`；展示时由脚本在正文后渲染 `（AI 生成，置信度 0.85）`，不把标注写进 JSON 正文。低置信度提示复核，但本身不阻止入库；来源矛盾或义项对应不明仍暂停。
- IPA、词形变化、可数性、及物性和语域标签须能追溯到具体来源或被标为待核验，不得由大模型仅凭直觉填入正式字段。
- 同义词和反义词按义项核验；输入词汇表内的语义候选也须核验，不因“两词都在表内”就判定有关联。拼写相似由脚本按最长公共子列公式与 `0.75` 阈值自动核验，记录 `automatic_passed`，只说明字面相似与可能易混，不推出语义相关。词组和搭配应检查形式、语域及与义项的一致性。
- 对四站证据不一致、来源网页结构变化、被登录或验证码阻断、保存冲突和 JSON 校验失败，报告具体缺口并保留可恢复检查点。
- 维护覆盖多义词、名动异读、不可数名词、不规则变化和近义词边界的标注样本；每次调整站点适配器、提示词或模型后运行回归，记录义项对齐、例句适切、来源支持及引用完整性结果。没有达到事先定义的发布门槛时停留在质量复核状态。

新版 `schemaVersion: 1.2` 的 `relationships[]` 支持 `linkStatus: lemma_only`：此时必须有 `targetLemma`、`targetSenseHint`、来源义项、Agent 核验状态及来源定位，且不得伪造目标词条或目标义项 ID。目标义项经独立核验后转为 `linked`，保留稳定关系 ID，并补入 `targetWordId` 与 `targetSenseId`。`pendingRelations[]` 仅存无法判断的候选；词族列表仅提供派生候选，直接派生须由 Agent 基于证据确认。结构化判断由脚本准备候选模板并校验全部候选 ID，状态机可暂停恢复。

目标词条单独建成后，单词状态机自动生成现有词面关系的义项链接审查包，Agent 可逐项链接或暂缓。脚本核对两端释义证据及文件哈希，冲突时暂停质量复核；链接时保留原关系 ID 并写入反向关系。未完成链接判断的单词运行不标记完成。

## 5. 本地文件与数据契约

在 `outputs/词汇星图/dicts/` 下按 lemma 首字母保存 `a.jsonl` 至 `z.jsonl`，每行一个完整词条 JSON；项目词表与项目熟悉度保存在 `projects/<projectId>/project.json` 和 `learning-state.json`；背诵计划保存在 `plans/<planId>.json`，按 `utils/references/dictionary-plan-v1.schema.json` 校验；全局收藏和界面状态保存在根目录的 `favorites-state.json`、`ui-state.json`。正式阶段清单以后保存在 `stages/`，当前“所有单词（测试）”由应用动态生成。搜索索引及图谱布局缓存可由上述文件重建，不作为第二份权威词条。词条内部对象使用稳定 ID；文件名不依赖词义顺序，避免重排义项时断链。旧 `outputs/英文词典/entries/` 词条经校验后迁入分字母 JSONL；旧 `outputs/词汇星图/entries/` 仅作为一次性迁移输入，较新修订写入 JSONL，同修订内容冲突暂停。迁移验证后清理旧文件，保留稳定 ID；恢复快照只在日志中归档。

已固化的最小模板字段分层如下：总词条含 `schemaVersion`、`wordId`、`lemma`、`familyId`、`pronunciations[]`、`inflections[]`、`derivatives[]`、`senses[]`、`pendingRelations[]`、`relationships[]`、`revision`、时间戳；每个义项含 `senseId`、词性、双语释义、语法与语域标签、`examples[]`、`collocations[]`、`phrases[]`；每个可发布内容项含稳定 ID、生成方式、`verificationStatus`、`sourceRefs[]`，AI 生成项另含 `confidence`。词条 Schema 1.5 的规则词形使用 `generationMethod: rule_derived`、`verificationStatus: pending`、空的直接 `sourceRefs`，并在 `derivation` 中记录 `ruleId`、`ruleVersion`、`basisSenseId` 与 `basisSourceRefs`；词性依据来源不可当作实际词形的直接来源。学龄段清单含阶段 ID、`wordId` 和被选义项及子项 ID，并保存核心／更多分组与顺序。项目学习状态以 `wordId` 映射熟悉度；收藏状态独立于项目和学龄段，以 `wordId` 映射 `favoritedAt` 和 `lastOpenedAt`，不复制释义正文；界面状态保存标签、图谱布局和五类关系显示按钮的状态。字段名和可空性以 `utils/references/dictionary-*.schema.json` 为准，应用不得自行发明不同版本。

收藏时两个时间字段均取收藏操作时间；此后每次成功打开该单词页时更新 `lastOpenedAt`。两类时间均通过 `utils/scripts/timestamp.py` 生成，使用项目统一的本地时间格式。取消收藏删除该记录，再次收藏重新初始化两个时间。收藏夹跨项目、跨学龄段共用，列表中的核心和其他释义从总词条及当前学龄段引用实时合成。收藏状态的字段、可空规则和模板由 Python 脚本生成并校验，不由前端自行定义另一套格式。

待采集关联词按义项保存在来源词条中。1.2 版将 Agent 已确认但目标未建的关系写入正式关系字段，保留目标词面、义项提示及证据；未确认的候选继续保存在待核验字段。旧版词条仍可验证。候选检索索引可从词条重建，不成为第二份权威数据；目标词条建成后按规范化拼写和义项证据消歧，再补双向链接。批次报告只汇总来源词条中的候选，不承担第二份持久数据契约。

本节字段已固化为可机读 JSON Schema 与最小模板；项目 Schema、分字母 JSONL 行格式及旧熟悉度迁移方向均已由用户确认。已确认的结构原则为“分词条 JSON＋引用清单＋状态文件”、义项及其子项粒度的阶段引用、AI 置信度两位小数，以及一个词条只对应图谱一个节点。模板和 JSON 示例由 Python 脚本生成并校验，不手写大段输出。应用保存前校验 schema、稳定引用与修订号，采用原子写入；遇到并发或外部改动不得静默覆盖。创建、更新及文件名时间戳遵守 `AGENTS.md`。

## 6. Web 应用与交互

### 6.1 共用框架

GUI 风格、间距、字体层级和前后端组织参考 `applications/背书工具/`：React、Vite、TypeScript 前端配本地 Python 服务。中间为类似 Obsidian 的多标签主体；标签可打开多个、拖拽排序、固定与关闭，收藏夹页可作为标签打开。词汇星图标签默认固定在最前面。启动时默认左右分屏：左侧图谱，点词后右侧打开该词单词页，同时将左侧图谱放大并以该词为中心聚焦，只显示该词及与它有关系的节点；分隔条可拖动调整宽度。用户可将单词页独立显示为标签，也可在分屏与独立标签之间切换。标签顺序、固定状态、打开的词页及分屏宽度自动保存并在重启后恢复。

单词页与待建词页共用最多一个未固定预览标签：打开新词替换原预览，已固定标签保留，已有标签只激活；双击或固定按钮可保留标签。设置和收藏夹独立保留，不替换词条预览。旧界面状态恢复时只保留最近或当前激活的一个未固定词条预览。

### 6.2 单词页

把总词条 JSON 与当前学龄段引用合成可读页面：首先显示单词、英美读音、核心释义及常用用法，再显示更多释义、词形、搭配、习语、例句和关联词。关联词按本阶段所选源义项筛选；词条级拼写相似关系单独标注，不冒充某个义项的语义关联。一个释义的词性、可数性／及物性、语域和其例句相邻展示。可查看每项的“来源支持”／“AI 生成”状态，规则词形另显“规则推导 · 待核验”；AI 生成项显示置信度及验证状态，不把置信度伪装成权威证明。

每个英音或美音音标后分别提供一个小喇叭，点击播放该单词对应口音的读音。播放地址为 `https://dict.youdao.com/dictvoice?audio={word}&type={1|2}`，其中 `audio` 使用 URL 编码后的单词拼写，`type=1` 对应英音，`type=2` 对应美音。有道接口仅作为单词页的播放来源，不作为词条 IPA、义项或其他内容的采集与核验证据。页面访问时逐个检查对应发音请求是否返回可播放音频；某个单词的某种口音接口不可访问、请求失败或返回内容不是可播放音频时，不显示该音标后的小喇叭，其他可用口音仍可显示。点击播放时若接口失效，隐藏该小喇叭，不影响音标和词条正文显示。已验证可播放的音频缓存在 `outputs/词汇星图/cache/audio/`，后续请求优先读取本地缓存；缓存不作为词条来源证据。

单词页提供“陌生”“见过”“熟悉”三个互斥按钮，按钮组紧贴内容，不在“熟悉”右侧留多余空白。每个词默认“陌生”，点击后立即更新学习状态，并在图谱上分别显示浅红、浅蓝、浅绿。学习状态按项目与词保存，不按义项或学龄段重复保存；同项目切换学龄段后沿用，切换项目时读取目标项目自己的熟悉度。派生词的每个词块左侧显示带颜色的竖向圆角标记。

已建词条的单词页右上角提供黄色五角星收藏按钮；点击加入收藏夹，再次点击取消收藏，按钮明确显示当前状态。关联词尚未建词条时，从关联词列表可打开占位单词页；该页只显示单词本身和关联说明（从哪个词及义项、以何种候选关系关联，并标明待核验），不展示推测的释义或其他词条内容，也不提供收藏操作。占位页提供“新建词条”按钮，经本地 Python 服务调用 `build-word-entry` 的单词状态机入口 `start-word` 并保存运行 ID；同一规范化单词已有进行中的运行时复用该运行，不因重复点击创建并行词条。页面通过 `status` 展示采集进度或暂停原因，通过 `resume` 从检查点继续；登录、验证码、质量复核或可重试错误均不能绕过状态机。词条通过 `verify` 校验并导入总词库后，占位页切换为正式单词页；失败或暂停时保留占位页和恢复入口。原候选关系仍须按证据核验，不能因词条建成而自动确认为正式关系。

### 6.3 收藏夹页

收藏夹每个条目显示单词、当前学龄段的核心释义和其他释义、收藏时间、最后一次打开时间。收藏时最后一次打开时间初始化为收藏时间；之后每次成功打开该单词页时更新。点击条目打开对应单词页。切换学龄段只改变释义展示，不拆分收藏记录；当前阶段没有合格释义时按现有待完善规则提示，不编造内容。收藏、取消收藏和打开时间的更新均按自动保存规则持久化。

### 6.4 词汇星图页

默认画布以当前项目词表为边界：显示表内已有词和待建词，以及表内已有词之间经过当前关系开关筛选的连接；已发布的屈折词形和派生词即使不在项目词表中，也作为所属词族的节点显示，不另建完整词条。选中词后默认只显示该词本身、同族词及该词的直接关联词；不沿同族其他词继续展开，也不保留无关的词表节点。节点拖动使用相连节点弹簧引力、节点间斥力与阻尼；所有节点可受影响，但影响强度随与拖动节点的距离平方衰减，近处位移明显大于远处；松开后批量保存位置。弹簧强度、斥力、阻尼和理想边长由 `config.yaml` 的 `graph.physics` 提供并经 Schema 校验。

每次为一个词加入其关联节点后，先扰动该词的位置并计算连接引力与节点斥力，再展示稳定布局。词族团须包围全部当前可见族内节点，团的范围内不得包含非族节点；团对非族节点的斥力系数由 `graph.physics.familyNonMemberRepulsionStrength` 配置。拖动后重新计算相关节点与词族边界。

图谱 API 按 `utils/references/dictionary-graph-v1.schema.json` 输出正式词条与占位节点。节点按规范化词面去重，记录 `kind`、`status`、词族归属以及适用的词形或派生来源 ID；`families` 列出团内节点 ID。`synonym_or_near_synonym` 仅在展示投影中归入“近义词”并标注“按规则分类”，原候选类型和待核验状态不改写。聚焦时优先展示词族及各类关系的一部分直接邻居，剩余数量可见，点“显示其他节点”再展开；搜索仍可定位候选词。

- 每个已入库单词一个圆形节点；每个词有且仅有一个 `familyId`，同族节点由更大的团包围。未能确认词族时，单词形成单成员团。屈折变化默认作为词条属性显示；词形变化与派生词无论是否已建词条都生成节点；未建词条以半透明灰色显示。单词、词形变化和派生词由同一个词族团包围。
- 同一词的不同词义不拆成多个圆点。词族归属是词条级的显式选择；同一个派生词关联多个来源词时由脚本合并词族；正式词条的 `familyId` 在发布状态机内一致化。同族节点使用更强的聚拢引力，并在布局结束时施加间距约束：多成员词族的每个节点至少与另一个同族节点保持配置间距，节点圆形不重叠，单成员词族豁免；圆心距离按实际节点半径之和加 `graph.physics.familyNodeGap` 计算，选中节点变大时同步调整。初始化、重新布局及拖拽释放后应用同一约束，词族避让以空间邻域索引筛选相邻词族，并缓存刚性词族的圆心及半径，整体平移词族以保留配置间距，再由外层圆包围；不显示词形、派生或其他同族连接线。初始化和拖拽使用相同的词族聚拢、节点排斥及词族避让规则。同义、近义、反义、拼写相似分别用不同颜色的边表示；同一词对有多种关系时，每种关系各有一条对应颜色的边。当前版本直接绘制具体词对边，点击查看对应词对及义项信息；总览中同一词对的多种关系边并排绘制，避免相互遮盖，选中后的义项连接策略保持不变。
- 选中词节点并放大后，在这个圆形节点的圆周展示当前学龄段所选义项的环形分段，每段标义项序号；较少义项时完整显示释义，密集时悬停或键盘聚焦可查看完整内容；从该义项引出的语义关系连接到对应分段。环段只是一个词节点内的义项标记，不生成独立义项节点。总览和局部聚焦均绘制具体词对边，并可查看对应义项。拼写相似关系连接词节点本体，标明“词条级关系”；边色始终表示关系类型，不用边色区分义项。低缩放时收起环段文字，悬停或键盘聚焦仍可读完整义项及关系说明。
- 环形分段的释义标签靠近所属节点，缩短标签到环段的距离，同时保留密集时的悬停和键盘聚焦查看能力。
- 词族团及同义、近义、反义、拼写相似边各有固定颜色，并提供图例；词对边由真实词条关系推导，点击边可查看具体词对与义项。关系更新后图谱同步重算，不把图谱边另存为第二份权威事实。节点填充色仍表示熟悉度或学龄段外状态，不用关系色填充节点，也不以多色描边表示多重关系。
- 词汇星图画布上方从左到右依次提供“初始化”“同族词”“同义词”“近义词”“反义词”“拼写相似词”“显示其他节点”按钮。五类关系按钮默认点亮，点亮色与对应词族团或关系边一致，熄灭时使用中性色；点击可在两种状态间切换，文字与按下状态也应能说明开关状态，不只靠颜色区分。无词节点被选中时，图谱显示当前项目词表内的单词、这些词已发布的屈折词形、派生词及当前可见节点之间的关系连接；五类关系按钮筛选关系与词族团，项目词节点始终显示。选中单词后，一个邻居符合多种已点亮类别时仍显示；熄灭某类时隐藏对应团或边，以及只靠该类别扩展的邻居，重新点亮时从词条关系重新计算。
- “初始化”将当前画布节点汇聚到中心附近，加随机偏移，再按图谱力学参数计算引力、斥力和词族避让并保存位置。`graph.initializeOnEnter` 默认为 `true`；每次从其他页面进入词汇星图时执行同一初始化，包括已保存的位置。初始化完成后的节点位置、平移和当前缩放构成本次进入图谱的恢复基准；手动再次初始化会更新基准。只加载并初始化当前选中项目的图谱；应用外壳先显示，项目清单、图谱和摘要在后台按需获取。单词节点点击后先打开右侧笔记容器，再加载对应词条；词条加载期间容器保持可见，不依赖全词库摘要刷新。
- 节点支持拖拽，画布支持按住 Alt + 滚轮缩放与拖拽平移；点击和拖拽节点不会选中节点文字，键盘操作与可访问名称保留。点击词节点时打开右侧单词页，同时以该词为中心平移并放大图谱；默认只显示选中词、与它同族的词形及派生词，以及通过当前可见正式或待核验关系与它直接相连的词，不沿同族词继续扩展一步邻居。选中词始终保留，五类关系全部熄灭时仍显示该词。五类关系按钮此时筛选当前画布的候选节点及关系，包括开启“显示其他节点”后恢复的候选；关系熄灭后隐藏仅靠该关系出现的邻居，重新点亮后恢复符合条件的邻居，同时符合多类关系的邻居在任一所属类别点亮时继续显示。点击其他词重新聚焦；再次点击已选中词、点击画布空白处或按 Esc 可取消选中，并恢复最近一次初始化形成的节点位置、平移和缩放；若初始化时有选中节点，取消选中导致节点半径缩小，则以该基准位置重新施加间距约束，保留基准平移和缩放。筛选改变可见词族成员时同样重新施加间距约束。无操作时不因异步布局重算改变视图。放大遵守 25%–400% 缩放范围和节点展示上限，密集邻居按需展开，不能为容纳全部邻居而取消放大。用户随后可继续手动平移和缩放；点击团放大并聚焦该团。拖拽结束后自动保存位置。
- “显示其他节点”仅在选中词时可用；未选中时保持熄灭并禁用。选中词后它默认熄灭；点亮后恢复当前画布范围内原本因聚焦而隐藏的其他候选节点，再次点击则恢复仅显示与选中词有关的节点。恢复出的节点也受五类关系按钮筛选；其中“同族词”只匹配与选中词同族的节点，与选中词不同族的其他节点须在当前画布范围内参与至少一种已点亮的同义、近义、反义或拼写相似正式关系。取消选中词时恢复当前按钮状态允许显示的其他节点，“显示其他节点”回到熄灭状态并禁用，五类关系按钮的选择保持不变。
- 词汇星图页右下角固定一行缩放控件，从左到右依次为缩放比例滑动条、显示当前缩放百分比且点击可选择常用比例的标签、`-` 缩小按钮和 `+` 放大按钮。缩放范围为 25%–400%，默认 100%；滑动条每格调整 5 个百分点，`-` 和 `+` 每次调整 10 个百分点，到边界时停止。标签提供 25%、50%、75%、100%、125%、150%、200% 七种常用比例。点击词节点自动聚焦、滑动条、标签选择、按钮及 Alt + 滚轮缩放共用同一缩放状态，操作后标签与滑动条同步更新。未按 Alt 的滚轮及松开 Alt 后继续到来的滚轮事件不改变缩放比例。
- 缩放低于 100% 时节点只显示单词；达到 100% 时，英文下方显示当前学龄段首个核心义项的词性及中文释义，词性使用常见缩写，英文词面完整显示，允许超出圆形节点；较长释义文字按节点宽度省略，完整词性及释义保留在悬停提示和可访问名称中；待核验标记另行保留。待建节点继续显示已有状态，不推测词性和释义；鼠标悬停及可访问名称同时包含已有词性和完整释义。
- 可切换是否显示当前学龄段之外、但与当前图谱词汇有关联的已入库词。先按来源词在当前阶段被覆盖的 `senseId` 筛选语义关系，并应用阶段外目标词显示开关；随后根据有无选中词确定全图或选中词的直接关系候选范围，最后应用五类关系显示按钮并绘制具体词对边。拼写相似边是词条级关系，不因阶段只覆盖部分义项而消失，并标明“词条级关系”。显示阶段外词时，这些词统一为灰色，灰色优先于学习熟悉度颜色；打开其单词页后可点“加入当前学龄段”。“所有单词（测试）”包含全部已入库词，不会产生学龄段外灰色节点。
- 加入当前学龄段并成功落盘后，灰色节点立即恢复为该词熟悉度对应的颜色。灰色可由图例和文字状态共同说明，不只靠颜色传达含义。
- 关系缺少目标词条时保留为待采集引用；默认仅项目词表内的待建词及已发布的屈折词形、派生词显示占位节点，选中单词后才展开表外待采集关系候选；待核验关系使用虚线和文字状态；可从已入库词条的关联词列表进入该候选的占位单词页。首屏最多展示 500 个词条及占位节点，团不计入此上限；超出的已入库单词通过搜索、聚焦或按需展开进入视图，并显示未展示数量。该限制只约束当前画布展示，不删除词条或关系，也不触发候选词建词条。总览只为当前项目词表构造词条节点、其已发布的屈折词形、派生词节点和当前可见节点之间的关系；画布布局按空间邻域计算节点斥力和词族避让，减少大词表的无效两两计算。

### 6.5 背单词页与背诵计划

背单词页的“首页”固定为第一个标签，展示已有计划；每个计划可在独立标签中打开、关闭，标签状态自动保存。每个计划块显示计划名、创建时间、当前轮数“第 X 轮”、当前轮中至少通过一次的不同单词数 `XX / YY` 和进度条。同一项目允许多个计划。右上角“新建背诵计划”打开模态对话框并禁用背景；选择项目、记忆方法（艾宾浩斯或葫芦背书法）、计划名、每天首次背诵单词数或首遍天数、开始日期。默认每日 50 词；输入每日数量时按整数向上取整计算首遍天数，输入首遍天数时按整数向上取整计算每日最多词数，并将词均匀分到所选天数（天数不得超过词数）。页面显示含首尾两天的首遍结束日期。可上下滚动的日历突出显示开始、结束及中间日期。

每个首页计划块右上角竖排“设置”“删除”按钮。设置打开可修改该计划信息的对话框；改变排程参数时清空该计划所有轮次的通过记录并重新排程。删除须二次确认，确认后删除计划并关闭其标签页。新建弹窗默认开始日期为当天，日历初始定位在当天所在月份；选定日期后，日历同时标出开始、结束与区间内各日。

创建艾宾浩斯计划时，Python 脚本按项目固定词表顺序提取稳定 `wordId`，调用 `schedule-ebbinghaus-plan` 状态机。Skill 输入 `n` 与 `daily_items` 或 `d` 二选一，产出逐日首次学习及复习批次；首遍结束日期与最后复习日期分开保存。请求、状态及中间文件遵循 `logs/` 约定，正式计划和排程遵循 `outputs/` 约定。每轮保存开始日、首遍结束日、最后复习日、当日通过记录和乱序选项。所有有安排的日期及单词由固定排程决定，不随熟悉度或乱序变化。到最后复习日且该轮每个有安排的单词均通过后，可从最后复习日的次日开始下一轮，轮数增加，当前轮进度重新计算。

创建葫芦计划时，调用 `utils/scripts/hulu_schedule.py` 中的应用排程状态机按项目词序分配每日单词；每遍每词只出现一次，`review_item_ids` 恒为空，不安排间隔复习。每天的分页由当前配置的每页词数决定。用户先学习当前页，再进入练习模式；练习模式可继续勾选或取消“通过”。前进时按已落盘的当前页通过数判定，使用整数条件 `5 × 通过数 ≥ 4 × 本页词数`，避免浮点误差。未达标自动返回本页学习模式，重新记忆后再练习。达到门槛才能通过按钮或右方向键前进；完成全部日期的分页后，沿用“开始下一轮”按钮，从上一轮结束日次日再次刷完整项目。

点击计划后右侧分屏显示计划页；每屏单词数由 `config.yaml` 的 `study.wordsPerPage` 控制，默认 10。每日固定列表分页成组，支持左右按钮和键盘左右键切组。学习模式默认展示词性和中文释义；练习模式默认隐藏，可逐条切换或使用“隐藏所有答案”“显示所有答案”。操作列依次为陌生／见过／熟悉、黄色收藏星、详情；练习模式另有通过开关，艾宾浩斯显示“稍后重试／通过”，葫芦显示“未通过／通过”。熟悉度写入该项目的学习状态，收藏写入全局状态，详情打开词条或待建词页。艾宾浩斯练习模式中当日未通过的词在正常组结束后进入重试列表，循环出现直到通过。每个词在当前计划至少一次通过时使当前轮 `XX` 增加一次，复习日重复通过不重复计数；每日是否完成按当日通过状态单独判断。切换背诵日期时恢复学习模式。

练习模式按空格时，按当前页词序每次揭示下一词的词性和中文释义；输入框和其他文本编辑控件保留原本的空格输入行为。艾宾浩斯计划仍按当日未通过词进入重试列表；葫芦计划以当前页 80% 门槛决定前进。

计划页在“今日 X 词”左侧显示两项比例，格式均为 `Z%（XX/YY）`：本页已通过数占当前分页显示单词数的比例，以及今日已通过数占今日排程单词总数的比例。进入重试页后，“本页”改按当前重试分页计算。背诵日期在打开计划页及跨日时自动切换为当天；当天超出计划日期范围时，以计划范围内最近的日期显示。

计划页有默认关闭的乱序开关。开启后显示“组内乱序”“组间乱序”两个按下／弹起按钮，默认弹起。组内乱序只打乱每组内部；组间乱序先打乱当日整个单词列表再分页，两者同时按下时按组间乱序执行。乱序仅改变稳定的展示顺序，不修改排程或每日单词集合；刷新及翻页后顺序保持稳定。

### 6.6 日历页

日历标记各轮计划覆盖的日期。点击具体日期，右侧显示该日所有相关计划、所属项目、首次学习词、复习词和当日完整单词列表。日历与计划使用同一份固定排程和日期映射。

日历每行显示两个月份，右侧分屏留出更宽的当日内容空间。每次打开日历页，在当天日期、计划及月份列表加载完成后，将日历内部滚动容器自动定位到当天日期，并默认展示当天内容；计划加载失败时明确显示错误，并按现有月份范围定位今天；定位完成后的日期点击和数据更新不反复拉回今天。

### 6.7 设置页与自动保存

左栏底部设置页提供学龄段选项及 `config.yaml` 的颜色、图谱力学参数和每页背诵词数设置。项目页已提供 TXT、JSON、JSONL 词表导入；正式学龄段仍待用户提供词表。当前词条生成流程不接受学龄段输入，也不意味着已有正式学龄段词表。

按项目维护的熟悉度、全局收藏与取消收藏、收藏词的最后一次打开时间、加入学龄段、标签排序与固定、分屏宽度、图谱位置、项目选择及学龄段变化自动写入本地状态文件。`config.yaml` 参数在设置页点击“保存配置”后校验、原子写入，并立即更新运行中的 GUI；配置版本冲突提示重新加载。离散状态操作在成功写入后反馈完成；拖拽和宽度调整可防抖，在指针释放时确保落盘。写入失败应保留内存草稿、显示明确错误和重试入口，不能显示“已保存”。临时悬停、动画和进行中的拖拽不需持久化。

五个关系显示按钮的状态属于界面状态，切换后按上述自动保存规则持久化，重启后恢复；首次启动默认全部点亮。“显示其他节点”是随当前选中词变化的临时状态，取消选中时重置，不作为独立的持久设置。

`applications/词汇星图/config.yaml` 是本工具所有界面颜色、图谱力学参数、进入图谱时是否初始化及每页词数的单一配置来源。按 `ui`、`learning`、`graph.initializeOnEnter`、`graph.family`、`graph.relations`、`graph.physics`、`controls`、`favorites`、`study` 分组；颜色统一为 `#RRGGBB`，由 `utils/scripts/dictionary_contract.py` 根据已确认的 Schema/template 生成并校验。前端使用经过校验的配置，不在组件或样式中写死另一套颜色；词族团、四类关系边、对应按钮点亮色和图例引用同一组颜色键。关系色初值为：同族紫色 `#8B5CF6`、同义绿色 `#16A34A`、近义蓝色 `#0EA5E9`、反义红色 `#EF4444`、拼写相似琥珀色 `#F59E0B`；熟悉度、学龄段外节点与收藏星的精确色值也由该文件规定。

## 7. 实施差异与验收

相对 `applications/背书工具/`，`build-word-entry` 提供词汇表批次状态机、可复用的单词状态机、四站浏览器适配器、表内关系发现与校验及唯一 JSONL 分桶总词库；本次应用新增学习、收藏与界面状态、多标签分屏、词义页、收藏夹页和交互图谱。正式学龄段引用清单在用户提供词表后创建，Schema 已定义。最长公共子列相似度、候选上界剪枝等通用确定性算法位于 `utils/`；收藏状态读写、时间更新、候选关联引用与图谱按需展开也由可复用 Python 脚本实现。共用状态机、结构化读写和校验逻辑位于 `utils/`，Agent 仅处理脚本无法可靠判定的少量结构化判断。应用 README、`application-audit.json`、阶段清单与状态 Schema、颜色模板及接口测试随应用交付。

新增或调整的 skill 必须使用可恢复的显式状态机；能由脚本确定的图谱筛选、关系展开、颜色配置模板生成与校验等逻辑优先固化为可复用 Python 脚本，跨 skill 通用部分放入 `utils/`，不依赖某次任务的特化脚本或 Agent 长篇填充。需新增输出格式时，先与用户确认 Schema/template，由脚本准备模板并扩充完整输出，Agent 只填写少量必须判断的内容。Markdown 中的大段表格、YAML 或 JSON 格式化数据也优先由脚本生成。

验收至少覆盖以下场景：

1. 输入含名动异读、多义和不规则词形的词，学习词典与 Thesaurus.com 的对应采集、义项对齐后得到一份可验证 JSON；登录或验证码导致可见浏览器暂停，用户操作后可恢复。
2. 同词不同阶段仅产生引用差异，总词条仍只有一份；删除或修改被引用义项时校验器发现失效引用。
3. 每个发布义项有例句；来源支持与 AI 生成逐项可查，AI 生成项的 JSON 置信度是 0.00–1.00 范围的两位小数数值。
4. 图谱中每词恰一个圆点且恰属一个团；同族由团包围、不连同族边，同义、近义、反义、拼写相似四类边颜色各异，同一词对有多种关系时分别画边。拖拽、点团聚焦、点词后右侧开页并放大聚焦选中词及与其直接有关的节点按规定工作，不扩展同族其他词的一步邻居。用至少含四个义项的词验收环形分段：可辨认当前阶段各义项对应的关联词，环段不是独立节点；词条级拼写相似边不绑定义项。右下角缩放控件的顺序、范围、默认比例、步长、常用比例选择和边界行为符合要求；聚焦、滑动条、比例标签、`-`／`+` 按钮及 Alt + 滚轮缩放后，显示的比例和滑动条状态同步；普通滚轮不改变比例。
5. 左侧切换栏按规定排列；图谱标签固定在首位，图谱页默认左图右词分屏；标签排序、固定、独立词页、分屏宽度、熟悉度及节点位置在重启后恢复。
6. “陌生／见过／熟悉”与浅红／浅蓝／浅绿一致；正式阶段启用后，阶段外关联词灰显并可加入。“所有单词（测试）”可验证全部已入库词。
7. 无效 JSON、采集失败、来源冲突、保存失败和修订冲突均给出可恢复状态；前端类型检查、构建及 1920×1080 桌面浏览器核心交互验收通过。
8. 词形与派生词链接、核心／更多义项的阶段差异、语域标签、来源冲突和标注样本回归均通过数据校验；阶段只覆盖多义词的部分义项时，单词页和图谱只显示这些义项的语义关联，词条级拼写相似关系继续按阶段关联词选择及阶段外显示开关展示。变更采集脚本后不能使已通过样本静默退化。
9. 输入一份含同族、同义、反义和拼写相似词的词表，批次既能发现网站返回的关系，也能发现词表内的相关词；拼写相似使用最长公共子列公式与 `0.75` 阈值自动确认，覆盖公共子列不连续、恰达阈值、低于阈值、别名、屈折词形及同族优先排除、跨项目增量、双向发布、待建节点和中断恢复等用例，候选剪枝不得漏掉达标词对。中途失败可恢复，同一词不会生成第二份总词条，待核验语义关系只按候选状态展示。
10. 收藏夹跨项目、跨学龄段共用；收藏后两个时间相同，打开单词页后仅最后一次打开时间更新，取消后再次收藏重新初始化；列表随阶段切换展示相应核心／其他释义，点击可跳转，重启后数据一致，写入失败有可恢复反馈。
11. 批次发现大量表外关联词时只产生与来源词条持久关联的待采集引用，不递归建词条或画假节点；应用重启后仍可由关联词列表打开只展示单词、关联说明和“新建词条”入口的候选占位页。按钮启动 `build-word-entry` 的可恢复单词流程，重复点击不产生并行词条；暂停时可按运行 ID 恢复，完成校验和导入后才显示正式词条，候选关系仍须独立核验。
12. 图谱首屏单词节点不超过 500 个，团不计入；超过上限时可看到未展示数量，并能通过搜索、聚焦或按需展开访问已入库词，不丢失关系数据。
13. 单词页每个英音／美音音标后分别显示可用发音的小喇叭，英音请求使用有道接口 `type=1`、美音使用 `type=2`；接口失败或未返回可播放音频的口音不显示小喇叭，其他口音及音标正文仍正常显示。
14. 图谱上方七个按钮的顺序、默认状态、颜色和开关反馈符合规定；无选中词时五类按钮筛选当前项目词表内的连接与团，项目词节点保留；选中词时筛选当前画布候选范围，选中词在五项全关时仍显示。熄灭后重新点亮可恢复符合条件的邻居；多关系节点在任一所属类别点亮时仍显示，单成员词族团跟随“同族词”，其项目词节点保留。“显示其他节点”未选中时禁用，选中后可切换当前画布范围内的其他候选节点，这些节点同样受类别筛选；再次点击已选中词、点击画布空白处或按 Esc 可取消选中，随后其他合格节点恢复，临时开关重置。五类按钮状态在重启后恢复，节点填充色仍表示熟悉度或阶段外状态。
15. 工具目录生成时有根目录 `config.yaml`，所有界面颜色均可从通过 Schema 校验的配置取得；词族团、四类关系边、按钮和图例的颜色一致，其他已有状态色不被关系色覆盖。模板及迁移规则在实施前与用户复核，调整配置后无需到多个组件中手改颜色常量。
16. `tmp/dicts/test_20_words.jsonl` 恰含 20 个来自指定来源、保留来源字段的单词；`tip`、`extraterrestrial`、`disgrace` 的混合词性拆成独立义项。`build-word-entry` 可解析 TXT、CSV、JSON、JSONL，并由同一批次状态机断点恢复。`dicts/a.jsonl` 至 `z.jsonl` 共 26 个文件存在，词条按首字母分桶、同 `wordId` 更新原行，迁移和校验能检测冲突。
17. 项目页能建立并切换词表、预览词表、编辑项目名和单词列表、确认删除项目；词典页跨项目搜索按完整、前缀、其他包含匹配排序，同层当前项目优先，并跳转词条或待建入口；左侧切换栏悬停展开名称，日历可上下滚动并查看计划日期详情。默认图谱显示当前项目词表单词、这些词的词形和派生节点及当前可见节点之间的关系连接；选中单词后只显示该词、同族词和它的直接关联词，不保留无关的词表节点。
18. 同一词在两个项目的熟悉度互不影响，收藏和最后打开时间全局共用；旧全局熟悉度仅迁入默认项目。节点拖拽使所有节点按距离平方衰减受影响，近处位移大于远处；位置批量保存，设置页保存 `graph.physics` 参数后运行中布局重新计算；无效参数被配置 Schema 拒绝。
19. 背单词页可为同一项目创建多个艾宾浩斯或葫芦计划，默认每日 50 词；首遍结束日期按输入与项目词数更新，首尾日期均包含。艾宾浩斯逐日排程由对应 skill 状态机生成；葫芦由应用状态机调用共享 Python 函数生成，新葫芦计划的 `scheduleRunId` 为 `null`，旧计划仍可读取且保留轮次与通过记录。艾宾浩斯跨日期复习不重复计入 `XX / YY`，每日重试直至通过；葫芦不安排复习，练习模式每页达到 80% 才可前进，未达到时回到学习模式。完成一遍后可手动开始下一轮。学习／练习答案显隐、空格逐词揭示、每组 10 词默认分页、左右键、项目熟悉度、收藏、详情及日历联动通过接口和浏览器测试。
20. 组内乱序只改变组内顺序；组间乱序打乱当日全表后重新分页；两种同时启用按组间乱序。每日单词集合及排程不变，重复打开顺序稳定。
