# 背图工具 PRD

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | 背图工具 |
| 目标平台 | Web 桌面端，主要适配 1920×1080（1080P） |
| 交付目录 | `applications/背图工具/` |
| 用户项目目录 | `outputs/背图工具/<项目名称>_<YYYYMMDDTHHMMSS>/`（标题经过文件名字符清理；冲突时追加 `_1`、`_2`） |
| 首要用户 | 需要遮挡图片局部内容进行主动回忆的学习者 |
| 本阶段范围 | 单机浏览器内编辑、练习、保存和导入导出项目 |

## 2. 目标

用户可以导入一张需要记忆的图片，在图片上放置可编辑矩形遮罩，为遮罩设置文本和提示属性，然后在练习模式下逐个点击遮罩以回忆被遮挡内容。项目可以保存到本地项目目录，重新打开后继续使用。

## 3. 非目标

- 不提供图像滤镜、画笔、路径、自由形状、图层面板或复杂排版。
- 不接入账号、云同步、后端数据库或第三方服务。
- 不支持移动端专用布局和触控手势优化。
- 不改变用户导入图片的原始内容；遮罩配置单独保存。

## 4. 用户流程

### 4.1 新建项目

1. 首次使用时先选择项目目录；也可以点击“新建项目”后由应用先请求目录授权。
2. 目录连接成功后再次点击“新建项目”。
3. 选择本地图片（PNG/JPEG/WebP）。
4. 以图片文件名（去掉扩展名）自动生成项目标题；创建后可在顶部标题框修改。
5. 读取图片原始像素尺寸，以该尺寸建立画布，图片铺满画布。
6. 创建项目目录并保存原图、缩略图和 `project.json`。
7. 新项目默认进入编辑模式。

### 4.2 打开旧项目

1. 首次使用时先选择项目目录；也可以点击“导入项目 ZIP”后由应用先请求目录授权。
2. 目录连接成功后再次点击“导入项目 ZIP”选择项目包，或从近期项目列表选择项目。
3. 读取 `project.json` 及关联资源并恢复画布。
4. 旧项目默认进入练习模式，矩形临时显示状态重置为填充显示。

### 4.3 编辑与练习

- 编辑模式：允许选中、创建、拖动、缩放、旋转和删除矩形；矩形填充使用 50% 不透明度。
- 练习模式：禁止几何编辑，只允许点击矩形揭示内容；点击工具栏“矩形”按钮时自动切换到编辑模式并进入矩形绘制工具。
- 矩形的点击行为由该矩形的 `mode` 属性决定：普通模式两态循环，提示模式三态循环。
- 练习模式提供“隐藏所有答案”和“显示所有答案”快捷操作；前者将所有矩形置于揭示后的状态，后者将其置于可见答案状态。

## 5. 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 项目标题输入框       工具栏                    模式切换开关 │
├──────────────┬───────────────────────────────┬───────────────┤
│ 近期项目列表 │          图像编辑器             │ 属性面板      │
│ 缩略图        │ 画布、缩放、选择框、旋转控件   │ 矩形属性       │
│ 标题/时间     │                               │               │
└──────────────┴───────────────────────────────┴───────────────┘
```

- 左栏展示可拖拽排序的项目列表；顺序保存到工作区根目录的 `project-order.json`，项目切换、重新打开应用或换浏览器后保持稳定。没有排序文件时按创建时间建立初始顺序。
- 中栏是画布和工具栏，画布外区域使用浅色中性色。
- 右栏展示当前选中矩形的属性；未选中时展示项目级画布属性。
- 页面按 1920×1080 设计，窗口缩小时允许滚动，不要求移动端重排。

## 6. 功能需求

### 6.1 图片与画布

- 支持上传 PNG、JPEG、WebP。
- 画布初始尺寸等于导入图片的像素尺寸，背景默认白色。
- 支持修改画布宽度和高度；调整后保持内容左上角坐标，超出区域裁剪，不自动缩放矩形。
- 提供“恢复原图尺寸”按钮，将画布恢复到原始图片尺寸。
- Alt+滚轮缩放画布视图，不改变画布像素尺寸；提供当前缩放比例和重置视图操作。

### 6.2 矩形编辑

- 新建矩形默认名称为“矩形 1”“矩形 2”…；名称重复时自动追加最小可用序号。
- 鼠标拖动矩形移动位置。
- 拖动四角控制点修改宽高；最小宽高为 8px。
- 矩形上方显示逆时针旋转图标，拖动图标旋转矩形。
- 可设置填充颜色（默认白色）、描边颜色（默认黑色）、描边宽度（默认 2px）。
- 可设置填充文本（默认空）、字号和文字颜色（默认黑色）；字号需限制在矩形内并在预览中裁剪溢出内容。
- 点击矩形后按 Delete 或 Backspace 删除。
- 新建矩形置于最上层；重叠时命中最上层矩形。
- 暂不提供图层前移、后移按钮。

### 6.3 矩形模式与点击状态

每个矩形有一个 `mode` 属性：`normal` 或 `hint`。

| 矩形模式 | 点击次数 | 显示状态 |
|---|---:|---|
| 普通模式 | 初始 | 填充、描边和原本的填充文本显示 |
| 普通模式 | 第 1 次 | 填充隐藏，仅描边显示；露出被遮挡图片 |
| 普通模式 | 第 2 次 | 恢复填充、描边和原本的填充文本 |
| 提示模式 | 初始 | 填充、描边和原本的填充文本显示 |
| 提示模式 | 第 1 次 | 填充、描边保留，显示提示文本并隐藏原填充文本 |
| 提示模式 | 第 2 次 | 填充隐藏，仅描边显示；提示文本隐藏 |
| 提示模式 | 第 3 次 | 恢复初始显示 |

- 提示模式的提示文本为空时，第 1 次点击仍进入提示状态，但不显示文字。
- 编辑模式不使用上述临时点击状态，所有矩形使用 50% 不透明度填充并显示编辑控件。
- 进入练习模式时全部矩形临时状态重置为初始填充状态，填充不透明度为 100%。
- 切换项目或关闭页面后不保存临时点击状态；重新打开时从初始填充状态开始。

### 6.4 属性面板

选中矩形后从上到下显示：名称、模式、提示文本、位置与尺寸（x、y、宽度、高度）、旋转角度、描边宽度、描边颜色、填充颜色、填充文本、字号和文字颜色。普通模式下提示文本禁用，提示模式下启用。名称在项目内必须唯一，重复时自动修正并提示。

所有属性修改均进入撤销历史，并即时反映到画布。

### 6.5 标题、保存与历史

- 编辑器上方提供项目标题输入框，标题修改即时更新界面并标记为未保存；通过“保存”按钮或 Ctrl+S 写入 `project.json`。编辑中的变更会自动写入工作区临时草稿。
- Ctrl+S 保存当前项目；保存成功显示短暂状态提示。
- 编辑状态未保存时自动写入工作区临时草稿；下次启动检测到草稿时，弹出恢复确认。
- Ctrl+Z 撤销，Ctrl+Y 重做。
- 历史覆盖标题、画布尺寸、图片导入、矩形增删、移动、缩放、旋转和属性修改。
- 打开旧项目后历史栈清空；临时点击显示状态不进入历史。

### 6.6 近期项目与目录操作

- 左栏条目左侧显示正方形缩略图：按图片和矩形合成，空白部分白色。
- 右侧两行显示项目标题和最后打开时间。
- 支持打开项目、重命名项目、拖拽排序和删除项目。
- 当前项目存在未保存修改时，切换项目必须先选择“保存并切换 / 放弃修改并切换 / 取消”。
- 删除项目必须二次确认，并删除该项目目录及其资源。
- 提供“打开目录”按钮：在支持 File System Access API 的浏览器中重新打开项目根目录选择器；浏览器不允许直接唤起系统文件管理器时，显示兼容性提示。
- 支持导出项目 ZIP 和导入项目 ZIP，导入前校验 `project.json` 与资源引用。

## 7. 状态机

应用状态必须通过显式状态机管理，禁止依赖互相矛盾的布尔变量组合。当前实现包含目录和文件选择、编辑/练习、导入导出、删除、保存、冲突等待等阶段。

```text
app_start
  -> requesting_workspace
  -> recent_projects
       -> selecting_workspace_for_create -> selecting_image_for_create
       -> creating_project
       -> opening_project
       -> selecting_workspace_for_import -> selecting_zip_for_import
       -> importing_zip
  -> editor_editing
       -> confirming_project_switch
       -> conflict_pending
       -> saving
       -> editor_practice
  -> editor_practice
       -> confirming_project_switch
       -> conflict_pending
       -> editor_editing
       -> saving
  -> exporting_zip
  -> deleting_project
  -> error
```

保存遇到 `PROJECT_REVISION_CONFLICT` 时进入 `conflict_pending`，用户可保留本地草稿或重新打开磁盘版本；保存进行中界面阻止重复提交。保存提交还会经过本地服务的修订校验、原子写入和连续读回校验。

矩形显示状态机：

```text
normal_visible -> normal_revealed -> normal_visible
hint_visible -> hint_text_visible -> hint_revealed -> hint_visible
```

保存状态：`clean -> dirty -> saving -> clean`；保存失败进入 `dirty` 并显示错误。

## 8. 本地数据目录与 JSON Schema

每个项目是 `outputs/背图工具/<项目名称>_<YYYYMMDDTHHMMSS>/` 下的独立目录；目录名由项目标题和创建时间生成，必要时追加冲突序号；`projectId` 保存在 `project.json` 中作为全局唯一标识，实际目录名也写入 `directoryName` 字段。

```text
<项目名称>_<时间戳>/
├── project.json
├── assets/
│   ├── original.<ext>
│   └── thumbnail.png
```

`project.json` 最小结构如下（字段名为实现契约）：

```json
{
  "schemaVersion": 1,
  "projectId": "uuid",
  "title": "项目标题",
  "revision": 1,
  "lastWriterId": "uuid",
  "createdAt": "2026-08-16T07:52:00",
  "updatedAt": "2026-08-16T07:52:00",
  "lastOpenedAt": "2026-08-16T07:52:00",
  "sourceImage": {"path": "assets/original.png", "mimeType": "image/png", "width": 1920, "height": 1080},
  "canvas": {"width": 1920, "height": 1080, "background": "#ffffff"},
  "rectangles": [
    {
      "id": "uuid", "name": "矩形 1", "mode": "normal",
      "x": 100, "y": 100, "width": 240, "height": 120, "rotation": 0,
      "fill": {"color": "#ffffff"}, "stroke": {"color": "#000000", "width": 2},
      "contentText": {"value": "", "fontSize": 24, "color": "#000000"}, "hintText": ""
    }
  ]
}
```

约束：`createdAt`、`updatedAt` 和 `lastOpenedAt` 使用本地时间、不带时区的 `YYYY-MM-DDTHH:MM:SS`；项目目录名中的时间部分使用 `YYYYMMDDTHHMMSS`，同类目录名冲突时追加 `_1`、`_2` 等后缀。`projectId` 全局唯一；客户端新项目以修订号 0 提交，原生服务在持久化锁内校验并递增，首次落盘为 1；后续保存继续递增，发现冲突时拒绝写入并要求用户保留草稿或重新打开；`lastWriterId` 标识最近一次写入者；矩形 `id` 在项目内唯一；`rectangles[].name` 在项目内唯一；坐标使用原始画布像素坐标，旋转角度单位为度；`schemaVersion` 变更时提供迁移函数；项目 JSON 不保存练习点击状态、当前选择、视图缩放比例和撤销历史。

## 9. 技术与实现约束

- 推荐 React + Vite + TypeScript。
- 画布可使用 Canvas/SVG 或成熟本地依赖，但必须保留可访问的属性面板和键盘操作。
- 使用浏览器 File System Access API 读取用户选择的图片资源，并使用本地原生写入服务原子保存 `outputs/背图工具/` 中的项目 JSON；项目 JSON 的提交、修订校验和最终读取由本地服务完成。
- `showDirectoryPicker()` 只能在目录按钮或新建/导入按钮的直接用户手势中调用；不得在图片或 ZIP 文件选择器的 `change` 回调中再次打开目录选择器。
- 不支持该 API 时，ZIP 导入/导出作为可用降级路径，并在界面说明。
- 应用运行产物和测试临时文件不得写入 `runtime/`；启动与服务日志写入 `logs/背图工具/runs/<run-id>/`，项目诊断事件写入工作区 `.__beitu_diagnostics__/runs/<run-id>/events.jsonl`。
- 所有外部输入（文件名、JSON、ZIP 内容）必须校验路径、类型、大小和 schema，禁止路径穿越。

## 10. 验收标准

### 新建与存储

- 能选择支持的图片并创建项目，画布尺寸与图片原始像素尺寸一致。
- 项目目录包含 `project.json`、原图和正方形缩略图。
- 重新打开项目后标题、图片、画布尺寸和全部矩形属性一致。

### 编辑器

- 能完成矩形的移动、四角缩放、旋转、删除和属性编辑。
- 填充、描边、文本和字号修改即时生效。
- 编辑模式填充不透明度为 50%，练习模式初始填充不透明度为 100%。
- Alt+滚轮、Ctrl+S、Ctrl+Z、Ctrl+Y 均可用。

### 练习行为

- 普通模式按两态循环。
- 提示模式按三态循环，并按要求显示或隐藏提示文本与原填充文本。
- 进入练习模式时全部矩形重置为填充状态；切换项目后临时状态不残留。

### 项目管理

- 项目列表按已保存的拖拽顺序显示缩略图、标题和最后打开时间；首次建立排序文件时按创建时间排序，之后点击切换项目或重新启动应用后顺序不改变。
- 重命名、删除（二次确认）、打开目录、ZIP 导入和导出可用；不支持的浏览器能力有明确提示。

### 质量与安全

- 无法导入损坏图片、非法 JSON、路径穿越 ZIP 或不支持的文件类型。
- 关键交互在 1920×1080 桌面浏览器中可操作，页面无核心控件遮挡。
- 应用目录包含启动说明和构建命令；构建、类型检查和关键交互验收记录在交付说明中。

## 11. 待确认的实现假设

1. “打开目录”受浏览器权限模型限制：Web 应用将打开目录选择器，不承诺直接启动操作系统文件管理器。
2. 1080P 按 1920×1080 桌面窗口作为主要设计基准；不制作移动端专用布局。
3. 画布修改为任意宽高时不缩放内容，保持左上角坐标并裁剪超出内容。
4. 浏览器不支持 File System Access API 时，ZIP 导入/导出是完整的可用替代路径。
