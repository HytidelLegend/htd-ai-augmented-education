# 安全说明

请勿在 Issue、PR、日志或提交中公开凭据和真实用户数据。漏洞报告渠道、支持版本和响应政策应由项目维护者在此补充。

火山语音 Skill 使用根目录 `VOLCENGINE_API_KEY`；ASR 允许进程环境变量优先，TTS 严格读取 `.env`，密钥不写入日志或正式产物。ASR/TTS 调用云端时会发送用户选择的音频或批准文本；回归测试仅使用 mock。确认稿与试听必须有用户明确确认及精确哈希回执，上游内容或参数变化后旧确认失效。

TTS 默认使用 Edge-TTS 本地客户端并将批准文本发送至 Microsoft 在线合成服务；不读取火山凭据。火山 TTS 严格读取根目录 `.env` 中的 `VOLCENGINE_API_KEY`，忽略进程环境变量；ASR 保留原有来源优先级。密钥不写入运行快照、日志或正式产物。
