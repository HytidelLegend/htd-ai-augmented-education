# 联想记忆参考案例

通用的编句、联想和场景原则统一见 [`utils/references/mnemonic-association-principles.md`](../../../utils/references/mnemonic-association-principles.md)。本文件只保存案例、正负面样例和质量校准材料。

以下案例必须保留在 Skill 参考资料中，用于校准“关键词 → 熟悉物象 → 多感官场景”的质量。成人、荤段子或猎奇表达默认允许作为记忆增强方式；仍应根据用户偏好和适龄要求控制表达强度。

## 用户提供的案例

1. 我国温度带从南到北依次为【热】带、【亚】热带、【暖】温带、【中】温带、【寒】温带。记忆方法：一股【热】气从下往上（自南向北）吹向【亚】洲，【温】暖了【中】国和【韩】国。
2. 全面依法治国的基本要求：科学【立】法、严格【执】法、【公】正司法、全【民】守法。记忆方法：谐音“荔枝公民”。
3. 【赋】、【比】、【兴】是《诗经》的三种主要表现手法。记忆方法：你的闺蜜一遇到【富】哥就【比心】，你说“你【神经】（谐音“诗经”）吧？”
4. 洋务运动的口号是“自强”、“求富”。记忆方法：“洋”联想到洋人，“自强”、“求富”提取关键词“强”、“富”。现在有些人想去找【洋人】结婚，找那种【强】壮的【富】哥。
5. 中国古代四大发明：造【纸】术、【印】刷术、【火】药、【指南】针。记忆方法：家里买了一台特殊的打印机，【只】能打【印】【火】影忍者的【指南】。

## 单易之医学案例

1. 【肛】门反射、【提】睾反射、【角】膜反射、【跖】反射、【腹】壁反射。记忆方法：谐音“刚提交支付”。
2. 关节退行【性】变、关节【强】直、关节【破】坏、关节肿【胀】、关节脱【位】。记忆方法：谐音“性强迫张伟”。
3. 血糖增高性糖尿病的四类：内分泌性、摄入性、应激性、代谢性。提取代表字词【内】、【摄】（谐音“射”）、【应】、【代】（谐音“戴”），组成有逻辑的句子：“要【内】【射】，【应】【戴】套。”
4. 舒张期额外心音包括肿瘤扑落音、奔马律、开瓣音、心包叩击音。提取首字【肿】、【马】、【开】、【心】，连成谐音句“【种马开心】”。

## 经用户认可的生物案例

- 原句：植物的六大器官是【根】、【茎】、【叶】、【花】、【果实】、【种子】。
- 联想句：“【跟】【警】【爷】去【花果】山找【种子】。”对应关系为跟→根、警→茎、爷→叶、花→花、果→果实、种子→种子。此句经用户认可，但因包含警察形象，不适合公域展示；仅用于内部质量校准。
- 原句：人体需要糖类、脂肪、蛋白质、水、无机盐和维生素六类营养物质。
- 提取：糖、脂、蛋、水、盐、维；调整为糖水、脂蛋、素盐。
- 联想句：“一颗【子弹】打中了正在喝【糖水】的【素颜】美女。”其中脂蛋谐音“子弹”，素盐谐音“素颜”。

## 经用户认可的化学案例

- 原句：一氧化碳还原氧化铜实验中，开始时先通一氧化碳再加热，结束时先停止加热，继续通一氧化碳直到冷却。
- 联想句：“一氧化碳早出晚归，酒精灯迟到早退。”

## 经用户认可的物理案例

- 原句：电磁铁磁性强弱与电流大小、线圈匝数和铁芯有关。
- 提取关键词：电【流】大小、线【圈】匝数、铁【芯】。
- 调整顺序：芯、流、圈。
- 联想句：“学习时进入心流状态的小圈子，叫做【心流圈】。”其中芯→心、流→流、圈→圈。

## 质量校准

- 视觉、动作、声音、触感或气味至少调用两种；抽象词先换成大众熟悉的物象。
- 顺序没有硬性关系时可重排；有硬性顺序时必须在场景中用路线、编号、动作或时间线固定。
- 牵强、过度复杂、引入更多生词、依赖无法想象的抽象关系时，`self_check.fit` 应为 `weak` 或 `bad`，并明确建议改用直接理解、分组、首字母或重复练习。

## 负面样例

以下五例是用户判定为生硬、牵强的负面样例，不得作为推荐联想：

1. 生物：把“绿色植物通过叶绿体，利用光能，把二氧化碳和水转化成有机物，并释放氧气”硬套成绿色工厂、电池、气球、水桶和糖果。
2. 化学：把质量守恒定律硬套成反应前后两端摆物体的天平画面。
3. 物理：把平面镜成像的正立、等大、虚像、等距硬套成“幽灵双胞胎”。
4. 数学：把“两点之间，线段最短”改写成弯路和直路的故事。
5. 英语：把完整句子中的单词逐个改成日历、书、连接绳等物象，反而增加语法记忆负担。

共同失败点：物象与要点没有简短、稳定的对应；场景只是原句的解释或图解；新增故事比原句更长；用户记住画面仍无法还原全部要点。遇到此类情况，`self_check.fit` 必须是 `weak` 或 `bad`，最终输出的最后一段必须明确提示“这个例子不适合用联想记忆法”，并给出更简单的替代方法。

## 不适合联想、适合其他方法的案例

### 顺口溜念熟即可

- 植物的六大器官是根、茎、叶、花、果实、种子。
- 原因：要点本身已经是短词，按固定顺序反复朗读即可；编故事会增加额外人物和画面。
- 建议方法：顺口溜、节奏朗读、遮盖复述。
- 药物吸收（起效）由快到慢的总顺序为：静脉＞吸入＞舌下＞直肠＞肌注＞皮下＞口服＞皮肤。
- 记忆方法：按首字顺序“静、吸、舌、直、肌、皮、口、肤”反复顺口溜朗读。
- 原因：这是八个短词组成的固定顺序，直接保留首字并按节奏熟读，比另编联想场景更省记忆负担；应判为不适合联想记忆法。

### 用逻辑推导记忆

- 体循环从左心室出发，经全身各处回到右心房；肺循环从右心室出发，经肺回到左心房。
- 记忆方法：左心室的壁比较厚，而体循环要走的路比较长，所以从左心室出发；出发和结尾的地方是交叉的。
- 燃烧需要可燃物、与氧气接触，并且温度达到着火点。
- 记忆方法：由日常生活常识直接推导。
- 生态系统由非生物的物质和能量、生产者、消费者和分解者组成。
- 记忆方法：先分成死的和活的；死的是非生物的物质和能量，活的再记生产者、消费者和分解者。
- 建议方法：因果推导、分类理解、概念图或直接复述；不要强行编联想场景。

### 适用性总规则

提取关键词加联想，适合“一句话包含多个要记忆的要点，且每个要点是一个关键词、一个词组或一个简短短语”。联想句可以与原知识相关，也可以与原知识无关；必须把关键词通过谐音、拆字、形象、动作或重新组合串成一句常见、自然、顺口、可复述的话。不得把关键词粗暴并列成生硬、陌生、没有语言节奏的句子。若句子中的多个要点分别都是完整句子，或每个要点需要独立解释才能成立，则优先判断为逻辑推导、顺口溜、分类、概念图或重复复述更合适，并在结果末尾提示不适合用联想记忆法。
