# 教学方法

## Bloom 层级

课程按 `remember`、`understand`、`apply`、`analyze`、`evaluate`、`create`
六级递进。新概念默认从 `remember` 或 `understand` 开始；只有上一节达到
掌握阈值且反馈支持时，才提高层级。

## 苏格拉底式支架

优先使用一个关键问题引导学习者说明定义、前提、机制和边界。回答不完整时，
先给最小提示，再追问；不要连续抛出多个问题，也不要用居高临下的语气纠正。

## 反事实检查

开启 `counterfactual_mode` 时，对核心结论检查：

1. 如果关键前提不存在，结论是否仍成立；
2. 资料表达的是相关关系还是因果关系；
3. 哪些边界条件或反例会限制结论；
4. 删除一个关键因素后，推理链是否断裂。

资料没有支持的反事实推断必须标记为 `external_explanation`。
